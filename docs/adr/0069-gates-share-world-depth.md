# 0069 门按可见底边参与场景深度排序

日期：2026-11-01。状态：已实现，待实玩验收。

此前门在 drawWorld 之前整层绘制，任何立体摆件都能盖住门，与已有的远先近后规则不一致。最小复现把两个箱子分别放在同一门可见底边之前、之后，旧版无法得到后场箱、门、前场箱的顺序。

门按 `(groundY - 可见底边) / DEPTH.scale` 入统一队列；门框、门板及符文一起绘制。不可用通行触发深度代替美术底边：43房北门的可见底边316位于步行带以外。贴花先画，站立摆件与人物的既有排序不变；没有素材时保留回退门。

这项决定只消除固定绘制层引入的错误，不推断录像未覆盖的布景位置。逐房遮挡、门板消失时序仍按0068要求核对录像，见 reference-video-audit.md 的SC-06。

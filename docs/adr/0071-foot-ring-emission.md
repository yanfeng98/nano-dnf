# 0071 脚圈按发光素材绘制，位于阴影之上

日期：2026-11-01。状态：已实现，待实玩验收。

承接0070固定完整环帧后，脚圈仍明显暗绿。检查发现绘制顺序为「脚圈 → 黑色地面影子 → 人物」，影子会压暗光圈；素材黑底只做了透明抠除，普通alpha绘制仍将暗绿边缘直接覆盖地面。

最小反馈回路：`node tests/browser/foot-ring.mjs`。它自行启动静态服务，进入深处43房，固定相机与人物位置，使用实际素材、渲染器及Canvas读回像素。参考为连续录像取样中的绿圈裁片，存放于 `docs/reference-evidence/02-foot-ring-reference-076.25.png`，仅作测试证据，不作为游戏素材。取样已从原视频重新按76.25秒请求解码，裁去左右黑边并归一到720×540，再取(380,336)起70×26区域。30fps录像的实际选帧误差不超过一帧。

依次检验的假设：阴影覆盖压低亮度、普通alpha导致暗边覆盖、发光强度与参考不一致。改为「阴影 → 脚圈 → 人物」，脚圈用lighter叠加，以四次原件绘制校准发光强度。没有重新绘制环形，也没有将录像像素用于游戏。这个增益是本作按画面测得的参数，不是原引擎配置的推断。

统一取样口径：绿/黄绿色像素中按R+G排序的前100个像素均值。录像样本约(203,254,81)，新版同机位约(212,236,64)；逐通道容差35/30/35，允许脚/草遮挡和场景差异。原版回归失败，新版通过。测试不声称逐像素一致；整体调色和暗角仍让绿蓝通道偏低。

城镇脚圈没有套用本次副本证据。原有死亡隐藏与地面锚点逻辑保留；亮环在靴子下方，不会盖住人物身体。

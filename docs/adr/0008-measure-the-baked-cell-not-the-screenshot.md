# 量烘出来的那一格，不量实机抓帧；并把这一行的尺做成 1:1

## Status

accepted（2026-09-27）。**推翻第六十八/六十九两轮对「实机比参考小 10–15%」的解释**
（那两轮判它是量法的账、不是尺寸的账），也**推翻本轮我自己先说过的「选错了源图层」**。

## 决定

**一、对齐一个招式与它的参考片时，量的是烘出来的那一格，不是实机抓帧。**

烘出来的那一格（`assets/effects.png` 里那一列）到屏幕之间只有一条可算的路：

```
screen = (client - window_centre) * k + (dx, dy),      k = fit_scale(window) * size / CELL
```

`window`、`size`、`dx`、`dy` 都是仓库里的数，所以这条式子可以**反过来解**：
把每一列按它摊回"他脚底为原点"的客户端像素，再和参考片上量到的框并排。
实机抓帧不能当尺子，因为它一帧里同时有 HUD 的红色技能图标、训练房里受光的墙面与
拱门、蓝紫地板上的混色、以及**血之狂暴开着时他那身红**——第六十八轮那张
「实机比参考小 10–15%」的结论就是这么量出来的，而真正的原因是下面第二条。

**二、要跟参考对齐的行，把窗口的尺度做成 1:1。**

`size = CELL / fit_scale(window)`，于是 `k = 1`，**一个客户端像素就是一个屏幕像素**；
而屏幕像素正是参考那把尺（**1 身位 = 84**）。这一行的 `window` 因此**就是尺子本身**：
它写 (-200, -180, 140, 40)，`fit_scale` = 120/340，`size` = 128 ÷ 这个数 = 363（render.js 取整 363，
偏差 0.09%）。

十字斩原来的窗口是 368 客户端px 摊进 128 的格子，`k` = 0.693，**整招被画成参考的 69%**；
每一层再各自乘上一个 1.44 去找补，于是行里的数**没有一个是能和片子对上的**，
而"对上"正是给这一行留的验收方式。

## Considered Options

> **继续量实机抓帧，只是把掩膜调严一点。** 否。抓帧里那个 69% 不是掩膜的账：
> 第六十九轮已经把掩膜松紧对过一次（strict 读 1.19 身位、loose 读 1.30），
> 而这一轮算出来的是 **0.693 这个乘数**，它在 `size` 里，是可以直接改掉的。

> **保留 0.693，把每层的 `scale`/`stretch` 反乘 1.44。** 否。数会变得不可读，
> 而且**下一轮再量一次参考就得再除一次这个系数**——它没有写在任何一行里，
> 只写在"上一版的人知道"。1:1 之后，行里的 `offset`/`stretch` **就是片子上量到的数**。

> **只把这一行的窗口改小、`size` 不动。** 否。窗口与 `size` 是一对：改一个不改另一个，
> 不是缩放变了就是取景变了，而这一行两样都要定住。

> **顺手把 怒气爆发 也改成 1:1。** 否，**这一条不追溯**。它的 `window` (182, -76, 513, 412)
> 若按 `size = CELL / fit` 该是 520.53，而 render.js 里是 317——它与参考对齐的方式是
> **另一个形状**（艺术在两种尺度上同时画：地上的环与三身位高的柱，环得靠 `size` 被单独调），
> 而且它的数是**照实机抓帧的经验**调出来的，没有一条能量出来的靶子被这一条推翻。
> 谁要动它，先按本条把它自己的框量出来，再决定要不要 1:1。

## Consequences

- **`assets/import_dnf_effects.py` 现在会打印每行的 1:1 `size`**（"one client px is … of a
  cell px, so `size` = … draws it 1:1"）。那是**给 render.js 抄的数**，不是注解；
  crossSlash 与 怒气爆发 两行现在都打印它，只有前者照抄。
- **十字斩这一行的每一层都是照着参考解出来的**，解算器在 `/tmp/xz/fit2.py`（工作产物、
  不提交）：一层一层单独合成、单独量，把该层的框驱到参考那一拍的框上。
  七层两三次收敛，量到的残差 ≤2px。**下一轮再动这一行，用同一个办法，别再靠眼睛。**
- **`docs/adr/0005` 那把尺（÷218×84）与这一条是两把不同的尺**：0005 管"参考上的像素换成
  本作的像素"，这一条管"本作烘出来的像素怎么落到屏幕上"。两把都要用，不要混：
  0005 的换算比是 2.595，本作这边那个被误当成 1 的系数是 1/0.693 = 1.443。
- **实机抓帧仍然是看"读起来对不对"的尺子**（颜色、亮度、和地板的关系——`0006` 那一类），
  只是**不是量几何的尺子**。两者分家，别再拿抓帧去调 `size`。

> ## 补记（2026-09-27 当天）
>
> **实机抓帧还差一样：竞技场的暗角，量颜色之前要先减掉它。**
> `drawVignette`（`src/render.js:930`）画在**世界之后、HUD 之前**，是一颗从 (480,243) 起、
> 内径 120 外径 620、边缘压到 `rgba(0,0,0,0.55)` 的径向渐变。他站在 x=110 时到圆心的距离是
> 450 → **压掉 36%**。所以同一块红，包里是 (240,0,28)，实机抓帧读到的是 (156,0,19)：
> 240 × 0.637 = 153，量到 156，差 1%。
>
> 这条要紧在两处：
> 1. **"实机比参考暗"这句话要拆开。** 暗角把 **Slayer、地板、特效一起压掉同样的 36%**，
>    所以"相对于画面"的亮度是没问题的。要按"相对于画面"去比，别拿绝对像素比。
> 2. **别在招式里补。** `0006` 立过这条；而这一条的旋钮也不在招式里，在**暗角**上——
>    那是"竞技场该长什么样"的决定，动它每个房间都变。谁要动，先把它当成一条场景决定来提，
>    不要当成某个技能的修正。

> ## 补记二（2026-09-27，同一天：这把尺**自己坏过几轮**）
>
> 本条说"把烘出来的那一格按渲染的算式反算回客户端像素，再和参考并排"。
> **并排那一步有一个必须钉死的细节：把这一层的哪一点落在他的脚上。**
>
> 我写过一张对照图，把那一层的左上角贴到了 `足底 + 窗口中心` —— 而那一层的左上角对应的
> 是客户端 **(−260, −250)**（`client_frame` 的取景框），于是整层被推到了**左上 (30, 70)**。
> 也就是说：**那张图里的东西，全都偏了 30px 左、70px 上，而我照着它judged了四五轮。**
> 代价是实的 —— 我据此判过"十 偏了、细了"（其实是好的）、"翼的落位错了"（一半是这张图的账）、
> 还在那一轮伸手去改了 `offset`。
>
> **规矩：叠图之前先写一行断言 —— 客户端 (0,0) 必须落在他的脚底那一像素上。**
> 数一量就知道 30/70 是不对的；不写这一行，眼睛看不出来。
>
> 同时记住**实机抓帧不是量分量的尺**（本条上半段已经说过几何，这一条是分量）：
> 同一拍上"实机 23.3% 对参考 12.0%"读起来像我太粗，其实那一帧里有**别的层**（细红线、
> 金弧）和**他自己那身红**（`RAGE=1`）一起落进了同一把掩膜。
> **要量分量，量烘出来的那一列**（只有它是单独一层），或者抓帧时把血之狂暴关掉。

> ## 补记三（2026-09-27，同一天：**参考帧 → 列号**的那一步）
>
> 量一拍的框，要先知道它落在**哪一列**上。这一行必须是渲染器自己的那三行，
> 一个字都不能改：
>
> ```
> progress = (n - 22) / 31        // 参考的 32 帧摊在 1.07s 的施法上
> local    = progress / 0.97      // EFFECT.timing.crossSlash = {from: 0, to: 0.97}
> col      = Math.floor(local * 32)   // skillEffectFrame 里就是 floor
> ```
>
> **不许四舍五入。** 我用 `round` 算了好几轮，差一到两格，而这一行的素材是
> **每帧宽度三倍一档**的（`gorecross_slash.img` 的 f5 是 54px，f6 是 17，f7 是 6）——
> **差一列，屏幕上就是差三倍**。解算器照着 f6 定了尺寸，实际播 f5 那两格就炸成 166 宽，
> 把参考 #32 那一拍整个盖住；而我在对照图上看到的「金弧太大太早」，追下去全是这一格。
>
> 由此还有一条**选帧**的规矩：**一层的尺寸只能照着它真正会播的那一帧来定**。
> arc2 原来播 f5→f6→f7，而参考那道金弧是「先慢慢缩、最后才收」（68 → 61 → 24），
> 包里的 f5→f6 是 54→17 **一刀砍掉三分之二** —— 两边的节奏对不上，所以那两帧不用，
> 定住 f5、用两档大小演它。**先量素材每一帧的宽度，再决定播不播帧。**

> ## 补记四（2026-09-27，同一天：**量动作要关架势**）
>
> 上面三条量的都是**特效**。这一招还有一半是**他自己的动作**，而它一直没人验过 ——
> 验法同样是把参考片那一拍的人和实机同拍的人并排，只是**抓帧时必须关掉血之狂暴**。
>
> **开着架势，他整个人是红的，站着和蹲着在缩略图上分不出来**，于是「参考 #26-#32
> 他是站着、剑向前平伸的，而本作让他蹲着扫了整整一拍（四分之一个施法）」这件事，
> 在前几轮的对照图上完全看不见。关掉之后一眼就看出来了。
>
> 规矩：**验颜色要开架势（`0006`），验动作与位置要关架势。** 两件事，两次抓帧。

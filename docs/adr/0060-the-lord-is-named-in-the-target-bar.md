# 领主只在左上角目标条上写名字，头顶与脚下不另画

**Status**: accepted（2026-10-21）。业主第三次实玩：

> 「领主的头上的文字，脚底下的光环」

## 决定

**所有领主**（幽暗密林 的牛头巨兽、幽暗密林深处 的暗咒猫妖）在场上只保留：
- 目标条上的名字（`Lv9 领主 - 暗咒猫妖`）与血条；
- 死亡光线/白剪影/碎块；
- 阶段效果：深处金色一闪，mirkwood 暴怒横幅。

拿掉：
- 头顶的 `drawMonsterName` 名条；
- 脚下的椭圆影子（普通怪保留，它给深度）；
- 半血后那圈**持续的红色脉冲环**（原来 `drawEnemy` 的 `enraged` 环）。

## 为什么

录像里 Boss 的名字就在左上角那块条上；脚下没有游戏自己加的一圈环。上一版把
“有名字的怪都写头顶”和“Boss 半血红环”当成了通用规则，深处实玩时被业主一眼看出。
普通杂兵的名条/影子不动——它们给的是“这只怪叫什么/站在哪一档深度”。

## 代价

- Boss 少了一圈影子，贴地感略弱；靠身体本身和地面带读深度。
- 半血不再有持续视觉；阶段变化只在触发那一瞬间（金色一闪 / 暴怒横幅）。实玩
  觉得“看不出来”再单开一条，不把红环加回来。

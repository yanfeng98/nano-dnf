# 参考的像素是参考的

## Status

accepted（2026-09-26）。

## 决定

**参考片上量出来的像素数不是本作的像素数。** 任何"参考里这一招有多高 / 多宽 / 多远"都要先换成
**身位**（÷ 参考里角色的身高，再 ×84），才允许出现在代码里。第十轮把 `01_崩山击` 上的"约 240px"
直接当本作像素用，于是这一招的跳跃高度是参考的 **3.0 倍**、前进距离是 **2.4 倍**——而这件事
**看是看不出来的**：两个数都在动，滞空与总时长又恰好对得上（那是另外两个独立量过的数）。
这一片把它们折回来：**250px → 83px**（顶点）、**100.8px → 42px**（前进），滞空 0.633s 不动。

**参考与业主的手感口径冲突时，以参考为准，并把冲突写下来。** 第四条反馈说「跳得不够高」时顶点是
138px = **1.64 身位**，已经比参考的 0.99 身位**高**了；也就是说按参考改，比他当时嫌矮的那一版还要矮。
他这一轮在知情之后选了"按参考砍回去"（`assets/dnf_effect_picks.md` 第十三轮），所以两句话不矛盾：
**在还没有身位这把尺的时候说的手感话，要按尺重算一遍再拿来当约束。**

## Considered Options

**保留旧的弧线、记为"刻意的手感偏离"——不做。** 那要有另一个来源支撑那个高度，而当时没有：
3.7 身位是拿第三把尺（既不是 84 也不是 218）算出来的，不是任何人的手感。

**折中到 1.5 身位——不做。** 折中会把"哪个数是对的"这件事永久悬空；要么按参考，要么给出一个
能量出来的新依据。

## Consequences

- **这一招的专属重力比世界重力*轻*（1653 对 2200），这与它原来的存在理由相反。** 原来是"又高又短"，
  所以比世界重；现在参考的滞空 0.633s 吊在只有 83px 上，世界的 2200 会 0.55s 就落地。
  `SKILLS.mountainBreaker.leapGravity` 这条机制留着，理由换过了——测试也跟着从 `>` 翻成 `<`。
- **`01_崩山击` 的升降量要用称号条量，不要用头顶。** `Lv.51 麻子哥` 那一条站着时恒在 y=489 一行
  （腾空时随身体整体上移），是片子里唯一不动的东西；头顶在 #35 之后被人和火盖住。切片 63 量身高
  用的也是它。
- **别的技能还没有照这把尺扫过。** 崩山裂地斩的弧线走的是世界重力（`leapUp -666`）与另一条参考片，
  数值来源不同，没有被这一条推翻；但"先换算再落地"这条规矩对它是同样有效的，谁再动它就要先量。
- **落地特效跟着人走，而不是钉在地面线上**（`EFFECT.draw.mountainBreaker` 撤掉了 `ground`），
  这条与 `0004` 那类"归属"问题不同：它是同一个参照系的错位——参考的火在他还在空中时就喷出来、
  并随他一起落到地上；钉在地面线上会让火在他落地之前就立好。**同一帧里量出来的两件事不能各归各。**

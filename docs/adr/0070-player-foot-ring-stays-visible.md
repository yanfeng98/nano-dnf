# 0070 副本人物脚圈保持完整亮环

日期：2026-11-01。状态：已实现，待实玩验收。

V2 75.25–78.25秒的半秒间隔原帧中，人物脚下黄绿色椭圆的可见宽度约60–64像素、高约20–22像素；部分被脚或草遮挡。对照见 `docs/reference-evidence/02-foot-ring-sequence.jpg`。

素材已经存在于ui.png：客户端 `sprite_common_etc.NPK` 中 `sprite/common/etc/movedestinationmark.img` 的六帧。旧渲染将这段落点扩散动画以8fps循环，其中f0只有13×4的暗点，缩放后几乎不可见；f3为79×25的完整亮环。因此副本脚圈固定使用原件f3，保留已测尺寸与贴地位置。未修改城镇脚圈，其出现条件与动画需另按城镇原帧核验。

不声称该客户端原件色调与录像完全一致；这里只消除周期性缩成暗点的问题。脚圈仍在人物前绘制，随人物地面位置移动，死亡后隐藏。

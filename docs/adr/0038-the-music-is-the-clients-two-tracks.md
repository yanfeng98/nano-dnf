# 音乐是客户端那两首，不是合成器

**Status**: accepted（2026-10-13）。业主在 grill 上的四条：
Q6 **选 b**（要 DNF 的原曲 —— 这一条**推翻了我给的推荐**，我推荐的是"留着合成器、照录像
重写一首"）、Q7 **选 c**（先去客户端拿，拿不到才从录像抠）、Q8 **选 a**（两首：关卡 + Boss 房）、
Q9 **选 c**（进 git，并在 README 与 ADR 里记出处）、Q10 **选 a**（删掉合成器）。

## 决定

**音乐改成读两个文件**，`assets/music/mirkwood.ogg`（关卡）与 `mirkwood_boss.ogg`（Boss 房），
走**同一条音乐总线**，进 Boss 房那一格就换（`Music.trackFor`，比的是 `dungeon.boss`
那个**格子序号**）。**文件从客户端的 `Music\` 目录取** —— DNF 的音乐不是藏在加密包里的，
就是那个目录下的明文 `.ogg`。

## 为什么不是"从录像里抠"

量过业主那条整场录像的音频轨：**AAC-LC 48 kHz 立体声 128 kb/s，整轨 RMS −12.37 dBFS，
峰值 +1.03 dBFS（超过满刻度）**，crest factor 只有 4.71 —— 响度是**被压扁过的**；
而且**六分钟里没有一次循环**（自相关只查得到 8.5–9 秒的乐句周期，唯一那个像 64 秒重复的
候选包络相关性是**负的**）。最干净的连续 90 秒落在**战斗打完之后那段平静的**上，
频谱还偏亮（10 kHz 高约 5 dB），可能叠着一层林间风声。

也就是说：抠出来的是**削顶 + 有损 + 不循环**的一段，循环点要手工硬接；
客户端那边是**无缝循环的源文件**，而且**关卡与 Boss 房是两首**。

## 现在这一片落地成了什么

**代码那一半做完了，文件那一半在业主手上**（客户端不在这台机器上，`docs/adr/0035` 的
那条约束）。所以 `src/main.js` 里是一个**过渡形态**：

- 两首文件按 `Music.TRACKS` 的名字去 `fetch` + `decodeAudioData`，接上就**循环**放，
  并**把合成器的定时器停掉**（一次只有一个在唱）；
- **文件没有的时候回落到原来那个合成器**（96 BPM、Am–F–C–G、10 秒循环）——
  所以这一层在文件到位之前是**惰性**的：管线先接好，东西到了就用；
- `getMusicState()` 现在把三样分开报：**该放哪一首**、**哪几首的文件在**、
  **现在唱的是文件还是合成器**（验收时要能一眼看出换没换到 Boss 那一首）。

**"哪几首真的在"由一份清单说了算**：`assets/music/manifest.json`。

这一条是被逼出来的：第一版是**直接去试一把**（读不到就回落），结果浏览器证明一次就红 ——
试一个不存在的文件，控制台留下一条 404，而那条"控制台无报错"是证明里的一条**硬门**
（`tests/browser/playability.mjs`）。把门放松是错的，留两条恒红也是错的，
所以改成**读一份一定存在的清单**：它说哪几首在，才去取哪几首。

清单由 **`npm run serve` 按目录里的实际文件重写**（`scripts/serve.mjs`）——
所以业主放好那两首之后**跑一次 serve 就同步了**，那是他本来就要跑的一步。
上线那条路也跟着补了：`.github/workflows/pages.yml` 现在按**清单**校验
"该上线的曲子真的进了 `_site`"（今天清单是空的，构建照样绿）。

## 被它推翻的（文件到位那一刻）

- **第十二切片起的那套合成器**（`src/music.js` 的音符排程 + `main.js` 的
  `scheduleMusicNote` / `pumpMusic`）整条删掉，连同 `tests/music.test.js` 里守着它的几条。
  **`src/music.js` 不删**：它留 `TRACKS` 与 `trackFor` 这两件（纯函数，单测着）。
- **`index.html` 那句「不需要资源加载」** —— 它早就不准了（页面本来就要加载九张图集），
  加上两条音频更不准。

## 代价与未决

- **文件还没到位。** 到位之前听得到的仍然是合成器。
- **到底是哪两个文件名要看客户端那一版**：`mirkwood.ogg` / `mirkwood_boss.ogg` 是
  2nd Impact 之后的写法；更老的版本用的是共用的 `forest01.ogg` / `forest02.ogg`。
  **以客户端里实际有的那两首为准**，名字不对就改 `Music.TRACKS` 两行。
- **音量对不上没人管**：合成器走 `MUSIC_LEVEL = 0.5`，而那两首源文件多半不是按这个电平
  做的。文件到位之后要**听一遍再定那个增益**（量法：拿参考片的 RMS −12 dBFS 对）。
- **换曲那一下是硬切**：录像里换房本来就有一下黑幕（`docs/adr/0030`），所以硬切大概是对的，
  但没有针对音乐量过。

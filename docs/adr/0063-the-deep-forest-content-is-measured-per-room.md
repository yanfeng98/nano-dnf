- **可见草带**：后缘（草地与树根/石墙交界）约 y=640 视频px，HUD 顶边约 y=900–910；
  高 **260–270 视频px = 82–85 世界px，占 1080 的 24–25%**。

  **深了一个量级。**

  另用 `visualBackY 320` 让草地仍从录像的树根线开始画；用同机位截图逐轮校准。

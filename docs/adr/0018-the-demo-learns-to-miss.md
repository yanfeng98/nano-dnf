# 本作第一次有了打空

## Status

accepted（2026-10-03）。它给本作引入两个此前**完全不存在**的属性，并按业主给的 DNF 口径把用词改正。

## 决定

**一、精英与 Boss 有「回避」，杂兵没有。** 血之狂暴的**命中**把这段回避补掉——这条架势的用武之地就是"跟硬的打"。
业主的说明书里写的是「攻击高等级怪物时会出现 Miss」，可本作**没有敌人等级**：
`ENEMY_TYPES` 里只有 `maxHp` / `xp` / `damage` 那一组数，`命中` / `accuracy` / `hitRate` / `evasion` 在整个 `src/` 里
**一个都不存在**，全代码没有一处 miss 判定。所以"高等级怪物"在本作落成了它真有的东西——精英与小 Boss、Boss。

**二、「命中」不是本作的一个属性，它只是这条架势的读数。** 没有基础命中率、没有命中数值、没有随等级递减的收益。
回避是**被攻击方**身上的一段打空，命中是**架势补掉它的那一段**；两者都不单独存在。
玩家不开架势打精英/Boss，就有概率打空；开着就没有。

**三、「硬直」落在玩家自己身上。** 业主的口径：僵直度是**你打敌人时敌人不能动的那段**，硬直是**你挨打之后多久能重新动**。
所以这条架势给的是**防守向**的读数——他挨打后的恢复变短。钩子早就有了：`PLAYER.hurtStun` / `player.hurtTimer`
（`core.js` 里 `damagePlayer` 给 `hurtTimer` 赋值那一处）。
它**不是霸体**：伤害一分不少吃（业主原话：「霸体是直接免疫控制，而高硬直只是缩短被控时间，该吃的伤害一点都不会少」）。

**四、用词改正：敌人那段叫「僵直」，自己那段叫「硬直」。** `CONTEXT.md` 原来那条把**硬直**定义成
"被打中后短暂无法行动的状态"、并把「僵直」列为要避开的叫法——**那正好是反的**。业主给的口径是权威，照它改。

**五、打空要飘字。** 参考片里没有这个读数，但参考片也不必给一个 demo 交代：不飘字，玩家读到的是
"我这一下没反应"，那看起来是 bug。DNF 自己也是飘一个 `MISS`。

## Considered Options

> **敌人有等级，越级才 Miss**（最忠于说明书那句"攻击高等级怪物"）。否。本作升级快、房间浅，
> 玩家越过级的场合很少——那就成了"效果不明显"，业主在暴走那片已经用一句「暴走效果不明显」否过同一类口径
> （`README` 第七十切片）。等级系统还会连带影响经验、掉落与全部现有回归基线，收益配不上代价。
>
> **全游戏基础命中率**（打谁都偶尔 Miss，架势补满）。否。它把运气塞进每一场杂兵战，
> 而动到所有战斗的基线正是本作"相同 seed 加相同输入必然得到相同结果"那条约定最不愿意付的代价。
>
> **把"硬直"做成给敌人的僵直**（双刀命中打出小硬直）。否。那不是 DNF 里「硬直」的意思（业主明确说它是"自身"的属性），
> 而且高频普攻挂僵直会变成近乎永久的控制。要"打击感"应该另起一条，别冒充硬直。
>
> **两条都不做**。否。说明书里这两条就没了，而业主点名要「实现这两个」。

## Consequences

- **这是一次全局难度改动，不只影响这一招**：精英与 Boss 从此对**所有**攻击都有一段打空，包括没开架势、
  以及别的技能。数值要调到"感觉得到、但不毁掉现有的战斗节奏"，并且在跑着的游戏里量过再交。
- **出血的 tick 不判命中**：持续伤害是已经落上的伤口，不该再打空。
- **用词变了**：`README.md` 技能表里"被硬直（鬼斩）时不能还手"那类说法，按新口径该读作**僵直**。
  `README` 是切片式 devlog，旧切片原样不动（同 `0016` 对"业主曾经用暴走叫血之狂暴"的处理）。
- **飘字需要一个新读数**——本作此前没有任何"这一下没打到"的表现，因为它不需要。
- 这条架势的代价（`0017` 的扣血）换的就是这里的可靠性：**打硬仗不掉链子**。谁要调弱这条架势，先读这两条一起读。

# 冠军怪是**同一具身体加一圈光环**，不是另烘一具

**Status**: accepted（2026-10-15）。业主在 grill 上答 **Q3 修正 选 a**（补齐录像那 7 个名字）。

## 决定

**一、`咒之赤哥布林` 与 `燃烧之投掷哥布林` 一具新身体都不烘。**

客户端那一族本来就是**同一套画布十具换色**（`goblin/body0..9`），而"冠军怪"
（champion）在客户端里是**另加一层 `champ*.img`**：`sprite_monster_common.NPK` 里
`champdark / champfire / champwater / champlight / champnone` 五套，**每套前后两层**
（`champ*back` 画在怪身后）。

录像里那只 `咒之赤哥布林` 身上那圈紫光正是 `champdark`（紫红地环 → 紫焰升起 →
紫色星屑，逐帧同形）；`燃烧之投掷哥布林` 是同族的火属性那一套。
所以两条新怪是**同一个兵种 + `champion: "dark" | "fire"`**：`ENEMY_TYPES` 里
它们指回已经烘好的那一行（`MONSTER.rows` 的别名），血厚一点、打得重一点。

**二、光环的尺寸走界面那一档（`UI_SCALE`）。**

`champdark` 的墨是 172 px 宽；按 1:1 画是**两个身位**，而它罩着的那只哥布林自己只有
0.9 —— 按 1:1 会盖掉半间房。乘 `UI_SCALE` 之后是 87 世界像素，正好比怪大一圈。

**三、摆在哪：**

`投石坡` 与 `苔石夹道` 各一只 `燃烧之投掷哥布林`（换掉一个杂兵/一个投掷哥布林），
`十夫长的营寨` 与 `腐叶浅沟` 各一只 `咒之赤哥布林`（换掉原来那只赤哥布林）。
**只换种类、不改只数** —— 每间房的怪数没动。

## 代价与未决

- **光环的帧率是本作自己的**（12 fps）：录像里那是火焰在动的节奏，没有逐帧量过。
- **它读不读得出来要玩过才算**：第一版抓帧里那圈紫光在深绿的草地上偏淡
  （`tests/browser/capture-hud.mjs` 的 `07-champion`）—— 太淡就加大 `UI_SCALE` 或加不透明度。
- **`champwater / champlight / champnone` 没烘**：这一关只用到紫与火两套。

# 左上角那块条是"当前目标"，霸体不吃浮空，战斗里的字各归各的量

**Status**: accepted（2026-10-13）。业主在 grill 上：**「按照推荐做」** ——
Q4（那块条挂在玩家卡下面、打中谁显示谁）、Q5（伤害数字照录像改样式）、
Q17（**做**命中状态词）、Q18（**等级归怪自己**）。Q19（Boss 那条 `ALERT!` 横幅）
选了"不做"，理由见下。

量与依据全部来自业主给的整场录像 `dnf-dungeon-videos/00001-幽暗密林.mp4`
（1920×1080，游戏画面居中 1440×1080）。**1 视频像素 = 84 / 265 世界像素 = `VIDEO_PX`**；
画在 HUD 上的还要再乘镜头远近（`HUD_PX` = `VIDEO_PX × zoom` = **0.5**）。

## 决定

**一、左上角那块条是"当前目标"的读数，每一只怪都有。**

不是精英专属：录像里普通 `哥布林` 一样有。它写三样 —— **类别牌**（`人型` / `野兽`）、
**`Lv{n} 名字`**、一条**红血条**，左边一个描金头像框放着怪的脸。

- 换目标时**整块换掉**（头像、类别、名字、血条一起），一帧里只有一块。
- 目标倒下时头像上打一个**红叉，闪三下**（0.25 秒亮 / 0.25 秒灭，共约 **1.2 秒**），
  然后整块一帧消失。
- **掉血那一截不是"追着填上来的条"**：是一块**白色块**占着刚失去的那一段，原地
  **由白褪到黑**（约 0.8 秒，途中经过粉 → 暗红 → `#860000`）。宽度不变，只有颜色变。
- 那块条挂在**玩家卡下面**（y 150，让开卡与它下面那行配速字）。

**二、顶部正中那条 Boss 血条整条删掉。**

录像里没有它 —— Boss 走的是**同一块条的放大版**（条长到 1068 视频像素，约等于整屏高）。
它顺带报的两件事跟着搬过来，不然是白丢的反馈：`· 狂暴` 并进那块条上的名字，
半血分界那条竖线留在血条上（那一条是**本作自己的**，录像里没有）。

**三、`无法浮空`：霸体不吃浮空。**

录像里那块浅色小字**自始至终只有一个词**，`无法浮空`。它讲的是**为什么这一下没把他挑起来**。

**所以这是一条玩法上的改动，不只是加一行字**：改之前 上挑 能把 Boss 从它的重踏里挑出来，
改之后只能挨着。要那句话有意义，它就得**真的**没用。带 `ignoreSuperArmor` 的招式
（嗜魂之手那两处）不受这条约束 —— 它们本来就是拿来破霸体的。

**四、战斗里那两句字各归各的量。**

| | 录像量出来 |
| --- | --- |
| 伤害数字 | 纯黄 `#FFFF00`、黑描边、**粗斜体**（向右斜 10–22°）、字高 **22 视频像素** |
| 它的走法 | **头 0.17 秒蹿上去 10 视频像素，然后停住**；活 **0.6 秒**；**到点直接消失，不淡出** |
| 命中状态词 | 冷白 `#E4E7ED`、字高 **29 视频像素**、活 0.4–0.8 秒；**钉在怪身上**（不是钉在数字上） |
| 怪头顶的名字 | 只有**有名字的怪**才有；字高 24 视频像素，浮在头顶约 15 视频像素 |

**五、一只怪的"是什么"只有一个地方：`ENEMY_TYPES` 上的 `label` / `race` / `level`。**

名字照客户端自己的叫法，等级照录像（**杂兵 `Lv4`、Boss `Lv7`**）。

## 被它推翻的

- **顶部正中 420×34 的 Boss 血条**（第五切片起就在那儿）。
- **`STAGES.*.bossName`**：那是同一个名字的第二份。它只被一个测试读，而且比录像里
  写的短（录像写 `领主 - 牛头巨兽`）。
- **伤害数字的画法**：「0.7 秒里匀速上浮 28 世界像素 + 边浮边淡出」整条换掉 ——
  那两条都是**错的读法**，把"蹿一下然后悬住"看成了"慢慢飘上去"。
- **`pushDamageEffect` 的 0.7 秒** → **0.6 秒**（35 个数字的中位数）。
- **`opts.launch` 无条件生效** → 霸体拦住它。

## 代价与未决

- **Boss 那条 `ALERT!` 横幅不做**（Q19 选 a）。几何与时序都量清楚了（绿色 `#8CC600`
  盖住类别+名字，橙色 `#FC8200` 铺 `ALERT!` 字样、字距 59 像素、两行错半格，整条
  从右往左分两段擦掉），**但它的含义没量出来**：那 41 秒里 Boss 一滴血没掉，
  可是"红色被不透明的横幅盖住"看起来一模一样。**做一个自己也解释不了的信号，
  等于教玩家读一个没有含义的东西。** 要定它，得在它挂着的时候去打 Boss、看红色右缘动不动。
- **血条长度每只怪不一样**（录像：哥布林 287 / 323 / 362，Boss 1068），量不出规律
  （只有三个样本）。本作**不编公式**：杂兵一律 362，Boss 1068。
- **怪头顶那个名字的颜色**量到两个值（哥布林 `#A975E5` 淡蓝紫、Boss `#DD04C3` 品红），
  分不出是"两个颜色"还是"同一个半透明的字压在两种背景上"。本作取**一个**色。
- **录像里那条条子比"第一次打中"晚约 0.7 秒出现**（只有一个样本，同一段里另外两间房
  几乎是开局就在）。本作做成**打中即显示**，没搬那 0.7 秒。
- **怪的种类还是那 5 种**：录像里这块条上写过 **7 个哥布林变体**
  （哥布林 / 胆小哥布林 / 青哥布林 / 赤哥布林 / 投掷哥布林 / 燃烧之投掷哥布林 /
  诅咒之赤哥布林），本作只有其中 3 个 —— 换色那几种要等客户端把 `body1..9` 烘进来
  （`docs/adr/0035` 的那条约束：客户端不在这台机器上）。

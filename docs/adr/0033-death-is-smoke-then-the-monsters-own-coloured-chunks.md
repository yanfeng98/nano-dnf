# 死是两段：白烟盖住尸体，烟散时炸成**它自己颜色的碎块**

**Status**: accepted（2026-10-11）。业主实玩 `docs/adr/0031` 那一片时报的：

> 「怪物死了，原视频是变成**肉块**，绿色的怪物是绿色的，黄色的是黄色，不是烟雾」

**他对，我上一片量错了一半。** `docs/adr/0031` 的第六节把"死亡 = 白烟、没有块"写成了结论 ——
那只量到烟那 0.2–0.4 秒就收工，而**炸块发生在烟散的那一刻**，取样窗口差半步；碎块又小
（游戏里 4–21 像素）、颜色淡，落在深绿草上被当成了草叶；再加上当时刚把"红球"正确定性成
掉落物，一并对"肉块"整条否定，把客户端 `bloodlarge` 素材全删了 —— 属过度纠正。

## 决定

**一、死亡是两段，不是一段。**

录像里四次击杀（69.5s / 156.1s / 246.0s / 328.2s）逐帧对下来是同一个动作：

1. **白烟**把尸体盖住，**尸体随烟一起没**（烟 0.1–0.4 秒）；
2. 烟散的**那一刻**青白圆爆亮一下（0.1–0.3 秒），尸体当场**炸成 8–15 块**飞出去、减速、
   坠地，**落地以后还留在草上**（有一块绿灯下留了 2 秒以上）。

`DEATH = { lie: 0.2, smoke: 0.2, burst: 0.25, chunks: 2.6, chunkCount: 12, bossSmoke: 0.95 }`：
一具尸体一条时间线，`enemy.dying` 从 `lie + smoke` 数到 0，途中滑过 `smoke` 那一刻推一条
`deathsmoke`，数到 0 时**同时**推一条 `deathburst`（圆爆 + 碎块）—— 烟盖着它散，所以尸体
不能提前撤；碎块是它没了以后的事。

**二、碎块的颜色是**这只怪自己的皮肤色**。**

业主：「绿色的怪物是绿色的，黄色的是黄色」。录像里量到的也是这样：绿哥布林炸出来的块
（147–163, 171–195, 118–141）和它皮肤（151,182,145）几乎逐像素同色；青哥布林出青块。
（**黄色怪全片没扫到** —— 55–345s 每 1 秒一帧过了一遍，只有绿 / 青 / 红 / 土黄四种怪。
所以"黄色的是黄色"这条按**同一条规矩**办，不是量出来的。）

做法沿用客户端自己的机制：那几帧**本来就是白色的形状**（`sprite/common/hiteffect/
splashbloodlarge.img`，颜色由引擎挑），烘图时按每种怪自己的色号染。色号量自
`assets/monsters.png` 每一行的身体像素（饱和度 > 0.2、中亮度，取中位数再提亮 30%）：

    grunt (74,159,149)   coward (96,149,96)   caster (106,128,149)
    brute (182,139,106)  elite (117,182,159)  boss   (159,96,96)

三张形状（那一帧里"一团血渍带小滴"，取**最大的一块**）→ `chunk_<type>{0,1,2}`，十八件。

**三、Boss 不炸。**

录像里 328.2s 它只是**一大团白云（约 230x175 游戏像素、0.95 秒）然后"啵"一下散掉**，
**没有碎块、地上什么都不留**。所以 `deathburst` 只推给小怪；Boss 只有 `deathsmoke`，
云更大（`bossSmoke`）更久。上一片说"云底下几块土色碎块"——查实是**地图上一块本来就有的
石头**（死前就在）。

## 被它推翻的

- **`docs/adr/0031` 第六节**「死是白烟，不是血块」：改成"白烟 + 它自己颜色的碎块"。那一片
  从烘图里删掉的 `bloodlarge` 素材，这次以**白色形状 + 按怪染色的三张**回来了。
- **`CONTEXT.md` 的「死烟」**：补上第二段与"碎块跟着怪的颜色走"。
- **一条测试**（"a dead monster lies for a beat, goes up in white smoke…"）按两段重写。

## 代价与未决

- **黄色怪那条没量到**（录像里没有黄怪），是按同一条规矩办的：碎块用这只怪自己的色号。
- **碎块的轨迹是解析的**（`h = vy*t - g*t^2/2`，参数由怪的 id 定死），不是物理积分：
  只读 `t`，暂停、慢放、重放都不会飘；代价是每块的落点是"算出来的"而不是"撞出来的"。
- **Boss 的云是硬切**（0.95 秒到点就散），录像里那一下还带一道白色射线 —— 没做。
- 碎块在地上留 2.6 秒然后一起淡掉；录像里最长的样本是"≥2 秒"，什么时候没的没量到。

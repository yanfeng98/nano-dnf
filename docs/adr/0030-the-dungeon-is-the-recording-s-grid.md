# 地牢是录像里那张图：一格一间房，门口按地图方向立

**Status**: accepted（2026-10-10）。业主在 grill 上：**「每一个房间的门口和地图上实际的
方向是一致的，不能一直往前走」**、**「地图要与视频一样，不能就五个房间」**、
**「Q1选择A」**（要真副本图，不是一路往前的一条线）；另外三条一起定在这一片里：
**「将第一个房间的陷阱去掉」→ 追问后是「以后也不要有这种陷阱」**、
**「木桶现在不能碰撞，也不能打碎…只有人能打碎，怪物打不碎」**、
**「怪物死亡要像参考视频一样变成血块」**、**「角色被打不能闪烁」**。

参考片仍是 `assets/dnf_src/bilibili/BV1d24y1P74G.mp4`（幽暗密林，362.6s）。
量出来的数字、证据 PNG 全在 `assets/dnf_src/bilibili/mirkwood/measure-*.png`。

## 决定

**一、地牢是**录像里那张图**，逐格量出来的形状，不是画出来的。**

    列:        0          1          2          3
    行0:    房间 E     走廊 ESW   走廊 ESW   走廊 SW
    行1:    房间 E     走廊 NSW   房间 N     走廊 NS
    行2:    房间 E◎    走廊 NEW   房间 W     房间 N     ← ◎ 是 Boss 房

- **4 列 × 3 行、12 格全满**。6 格画成房间（圆角方块）、6 格画成走廊（线），
  一格算哪种由客户端图块自己决定（`assets/import_dnf_minimap.py` 那 21 个形状）。
- **相邻不等于相通**：(1,1) 与 (2,1) 贴在一起，却各自只开三个方向（(1,1)=NSW、
  (2,1)=N），所以 11 条连接一条条写在 `Core.MIRKWOOD_DUNGEON.links` 里，
  每格的门（`exits`）**从连接算**，不另写一遍。
- 量法：把 `act1.img` 的 18×18 格缩到录像的 40.5 px 格距上滑窗比，命中帧 RMSE 6.2–9.0、
  次佳 10.5–16.3；整张图从方形窗口出现的第一帧（76.0s）就**画满了**，之后 250 秒
  一格没变过，**包括他从没进去过的那四格**。
- 起点房 **(2,1)**、Boss 房 **(0,2)** 钉死；**哪间房摆在哪一格按种子洗**，但**形状一格不动**。
  洗的是内容（第一次玩和第五十次玩不是同一批房间），不是地图。

**二、门口按地图方向立，四个方向各一副客户端美术。**

`sprite_map_pathgate.NPK` 里就有整整一族：`granfloris{side,up,down}gate02` ——
侧门 131×240（左右走的那种拱）、后门 157×198（立在房间后边）、下门 192×118
（躺在你面前的地上，透视已经烘进画里）。所以"门口方向一致"不用自己画。

- **清过房，这一格的门才全开；没清，只有他进来那扇能走回去**（DNF 的规矩）。
  门画成暗的 + 拱里插着那扇拦门板（`granfloris*door02`）；清完了亮起来，门板不见。
- **他往哪走进来的，就从那边出现在下一间**：东门进来站在右边、上门进来站在后边。
- **换房那一下**：旧画面直接切掉、**黑的盖满一帧**，新房间在 **0.3 秒**里淡进来
  （实测：整屏亮度 121.333s 掉到 4.2，然后八帧爬回 58）。

**三、走道格也是房间**，不是过场。录像里他在 (1,0)/(1,1)/(1,2) 各待了 24 / 38 / 41 秒，
画面里都有哥布林 —— 所以 12 格都摆得起一场仗；走道那一档给的是"挡路的"两只，
尽头那几间才是三只。

**四、塌陷地板整套删掉。** 业主：「以后也不要有这种陷阱」。`Core.HAZARD`、
`updateHazards`、`state.hazards`、渲染里那几块裂开的板、提示器里那条、以及
"开局房不许带陷阱"那套抽签，全部拆掉。它是从**已经删掉的「沉没礼拜堂」**搬过来的
（`docs/adr/0026` 第四节），本来就不是幽暗密林的东西。

**五、木桶变成实心的可破坏物，而且只有他打得碎。**

- 客户端的桶自己有 13 帧（`sprite_map_breakableobject.NPK :: barrel.img`）：
  **第 0 帧是完整的桶，1–12 帧是飞散的木片和铁箍**。所以"打碎"就是把那 12 帧放出来。
- **人和怪都撞得到它，只有他的攻击打得碎**（业主原话）。怪的挥击、怪的身体都不碰桶。
- 偏移是量出来的：每帧相对完整那只桶 ink 左上角的 `(dx, dy)` 烘进
  `SCENE.barrelBreak`（`assets/import_dnf_scene.py --table` 印的，别手抄）。
- **摆桶的规矩**：怪不会绕路，所以桶别摆在小怪必经的直线上，否则有怪会顶着它原地推。

**六、怪物死亡 = 倒地 0.2 秒 → 原地炸开 → 身体不再回来。**

时间线是量出来的（四次独立击杀对得一样齐，用的是经验条跳格）：

- **青白色圆爆**（`monsterdieflash`，白核 + 青边）：亮 3 帧 = 0.10 秒，最大 129×83 游戏像素。
- **9–14 块红肉块**（`sprite/common/hiteffect/bloodlarge` 的第 1–3 帧）：7×11 ~ 16×21
  游戏像素，**悬在空中不落、不上飘**，半秒内散掉。位置由这只怪的 id 定死，
  不跟着帧随机 —— 不然一具尸体半秒钟里会变十几副样子。
- **地上不留血泊、不留尸体**。躺下是"击倒"，0.2 秒后会站起来，和死是两回事。

**七、他挨打不闪。** 录像里挨打那 20 帧**每一帧人都可见**，也没有一帧变白，
只有 0.33 秒的受击硬直。所以无敌时的一闪一闪和挨打那一下的白闪**两条一起删**。

## 为什么必须这么做

**"门口和地图方向一致"只有在门按方向立的时候才成立。** 上一片的地图（`docs/adr/0029`）
被业主一眼看穿：「不能一直往前走」—— 那时换房的条件是 `player.x >= rightWall - 60`，
不管图上那一格开的是哪边。现在门是四方向的，出门的条件就是他站进那扇门：

    E: x >= rightWall - 60        W: x <= leftWall + 60
    N: z >= 地牢深度 - 46 且 |x - 上门 x| <= 110
    S: z <= 46 且 |x - 下门 x| <= 110

**"不能就五个房间"是形状问题，不是数量问题。** 一局打几间房由路线决定（录像里他走了 6 格：
(2,1)→(2,0)→(1,0)→(1,1)→(1,2)→(0,2)，右边四格整局没去），所以**卡片上那句「房间 2/5」
没有意义了**：它改成只报房间名，清完房改成指路。

**这一片的形状全是量出来的**：格距 40.5 视频像素 = 18 游戏像素（和上一片同一个尺子）、
窗口在右上角（不是左上角）、标题条 26.1 游戏像素、上门的 x 是 0.673 / 0.492 / 0.469
（三处看得见的），南门被 HUD 挡死、量不出位置，一律 0.5。

## 被它推翻的

- **`docs/adr/0029` 第三节**：「路是一条楼梯」——那时客户端只有 {E,S} 与 {N,W} 两种
  两出口房间，所以任何一条路都只能往西往南。现在的形状**不是一条路**，是一张图，
  拐弯和岔路都在。那一条明说过「要真岔路，就得改跑图，那是另一片」—— 这就是那一片。
- **`Core.layoutForSeed` / `rampRooms` / `roomThreat` / `RUN_COMBAT_ROOMS` /
  `gauntletIndex`**：一局的房间顺序不再抽签，所以整套抽签逻辑删掉。种子现在决定的是
  **哪间房摆在哪一格**。
- **`docs/adr/0026` 的「6 房跑图」** 与它的 `hazards`：那一整套塌陷地板没了。
- **`state.roomIndex` / `state.layout`** → `state.cell` / `state.dungeon.cells`。
  界面上的「第 N 层」全部改掉（`src/summary.js` 的"到达"一行现在报
  「走过 N 间 / 图上 M 格」）。
- **HUD 房间卡片**的「房间 2/5」一行 → 只报房间名，清完房改成「已清空 · 门口亮了就能走」。

## 代价与未决

- **怪不会绕开木桶**（没有寻路）。撞上就顶着，所以桶的位置是摆设的一部分，
  摆的时候要让它避开小怪从出生点走到玩家那几条线。
- **南门在本作的画框里几乎看不见。** 本站地面线 430、技能栏从 444 起，门前那片
  "观众这一侧"只有 14 px，而客户端那扇下门有 118 px 高。所以南门只画一圈地上的光
  （同一族 `granflorisdownlight`），够读"往这边下去"；参考片里它也被 HUD 挡得只剩个顶。
- **Boss 格 (0,2) 是房间还是走廊读不出来**：红牛头标记（16×14 游戏像素）把整格盖住了，
  剩下的边条两边都像。它的东出口短枝看得见，所以"是个带东出口的格"是确定的；
  按地牢设计把它当 Boss 房。
- **门口道具的出现/消失规律没定出来**：(1,0) 里他进来的那扇东门在 124.2–124.6s
  平滑淡出，别的房间却挂了几十秒。所以"清完房门口亮起来"是**本作自己的读法**
  （光是我们加的），不是从录像里抄的。
- **12 格各是一间房，内容只有 12 条**（6 间老房 + 6 间新写的走道房）。形状和内容都还
  只有幽暗密林这一关有；另外 7 关仍是 `rooms: []`。
- **一局变长了**：以前固定 5 间，现在走到 Boss 大概 6 格、把图清干净是 12 格。
  跑图 bot 的承伤横线因此从"四分之一血"抬到"一半血"（量过十二个种子：38–67 / 156–176），
  它守的是"读着冷却走的策略能不能走完这一关"，不是"一路不挨打"。

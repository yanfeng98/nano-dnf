# 进副本那一串：过场插画 2.04 秒、全黑 0.3 秒、关卡名挂 4.2 秒

**Status**: accepted（2026-10-15）。业主在 grill 上答 **Q9 要开场插图与关卡名那两行**。

量自录像的 53.87-61.3 s。**换算**：`画布x = (录像x − 240) × 0.5 + 120`、`画布y = 录像y × 0.5`。

## 决定

**一、`beginIntro` 只挂在"从地区地图进关卡"那一步。**

```
三帧全黑 → 插画淡入 0.30s → 保持 1.50s → 淡出 0.24s → 全黑 0.30s
→ 房间淡入（很慢，约 2 秒才满亮）+ 两行关卡名跟它一起亮
→ titleT 走完 4.2 秒时用 0.17s 快速淡出
```

**那 2.34 秒不推世界**（`step` 直接返回），所以过场与加载的那一段**不算进这一局的用时**。
重开一局（R / N）**不重放** —— 那是在同一间已经打过的副本里再来一次。

**二、插画是客户端那张 `sprite/map/cutscene/lorien.img`。**

800×600，铺满世界窗口（窗口正是 4:3，与它同形）。**外面那圈 48 px 的金棕雕花木框
这个客户端里没有**：过场图是光板一张，全客户端 639 张 ≥500×380 的图里没有框这种东西
（`assets/import_dnf_ui.py`）。所以照它**画的那张画**烘，**框不自己画**。
注意别认错：`granfloris.img` 是另一张白天森林 + 石拱，**没有人物和火山**。

**三、两行关卡名是同一张图。**

`sprite/map/title/mirkwood.img`，14 帧（发光脉动），272×98 —— 上行大字 `幽暗密林`、
中间一条细线、下面 `Gran-Floris 格蘭之森`。尺寸对得上：那 272 px 的画在录像里占
443 视频px，正是**界面那一档的 ≈1.6 倍**（`UI_SCALE`）；换算到本作是 217.6 画布px，
量到的录像字块是 221.5 —— 差 2%。

**四、它插在世界的深度队里、站在他那一档上。**

录像里**人挡在字前面**（`docs/adr/0044` 的抓帧里他就站在字中间），所以它既不能画在
整趟世界之后（会盖住人），也不能画在 scenery 之前 —— 第一版就是这么**整块消失**的：
它被自己那一带的草丛吃了。跟人同一个 z、排在人前面，这一条天然成立。

## 代价与未决

- **框没画**：真要就得照录像描一个，那是自己画美术，与「素材去客户端找」冲突。
- **`格蘭之森` 是繁体**：客户端那一版就是繁体，CN 补丁包里同名同尺寸、内容一样。
  录像里写的是简体 `格兰之森`，**这一处对不上，暂时照客户端**。
- **关卡名只做幽暗密林**：`sprite_map_title.NPK` 里 150 条其它关卡名都在，照抄那套命名即可。

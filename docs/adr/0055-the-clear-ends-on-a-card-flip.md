# 通关后是四选一翻牌，不是右上角一只小宝箱

**Status**: accepted（2026-10-18）。业主：「最后的翻牌奖励不对」。

## 参考里是什么

录像约 343.5–356s，战绩页之后另起一页 `奖励`：

1. 蓝色魔法阵 + 左边怪物列表；
2. 中央红木宝箱打开，白青爆闪；
3. 四张青色牌背 → 同时翻成金色宝箱面；
4. `请选择奖励卡牌` + **3→2→1**，超时**自动选最左一张**；
5. 选中后牌行收走，左边出现玩家名条与物品卡：本局是「古老的法杖 ×1 + 3526 金币」。

本作原来只有右上角一只小宝箱与一行 `+这一局捡到的金币`（`docs/adr/0045` 明确写了
「四张卡的选没有做」）。这一条把它补成真正的两页。

## 决定

- 新增纯状态机 `src/reward.js`：`stats`（沿用现有战绩页 3s）→ `chest`（1.2s）→
  `cards`（0.5s 后翻面，3→2→1，超时选 0）→ `reveal`（2.5s）→ `done`。
  总共约 13 秒（参考约 22.5 秒，按本作已有的结算节奏压缩）。
- 客户端素材：魔法阵 `reward_ver2.img` f33、深蓝面板/五芒星 f35、金色牌面 f36
  （已有 `rewardChest`）、青边牌框 f41 + 宝石纹样 f42、玩家名条 f60、横带 f103、
  倒计时金色数字 f104–113；红木宝箱复用已烘的 `chestOpen`。标题/提示用 Canvas 字。
- 奖励：**一件物品 + 一笔金币**。物品从客户端自己的青色名池（`Core.LOOT.cyan`）里
  按种子确定地抽一件；金币 `500–3499` 也按种子确定。**本作没有背包/物品系统**，
  所以物品名只做展示与日志，不产生装备效果。
- 点击牌或按 `1–4` 可以提前选；不选就等倒计时。`F3` 仍然随时回地区地图；
  `done` 之后那行提示才出现。
- 旧的右上角小宝箱与 `+金币` 行从战绩页删除，避免一次通关领两次奖。

## 代价

- 奖励不改变任何数值；它和已删的强化卡不是同一条回路（`docs/adr/0053`）。
- 物品池只有名字，没有图标；参考里那根法杖的图标客户端没有单独分件，
  本作在物品卡里用文字 + 金币圆点表示。
- 翻牌结果按种子确定，所以同一个种子重打会拿到同一件物品——这是刻意的，
  和种子决定房间/敌人的口径一致。

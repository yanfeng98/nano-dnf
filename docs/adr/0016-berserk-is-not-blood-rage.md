# 暴走与血之狂暴是两个技能

## Status

accepted（2026-10-02）。它改的是**用词**，不改玩法：`0003` / `0004`（红归架势）不受影响。

## 决定

训练房把这一对拍成了两条不同的片子：

- `assets/dnf_src/bilibili/skill-clips/05_暴走.mp4`（103 帧）：他**全程站桩**，只在中段头顶浮起一枚图标
  （青白星芒 `#63–68` → 橙金圆盘 `#67–72` → 金色徽记 `#73–93`，`#94` 消失），身周挂着四条
  **若隐若现的暗红竖丝**（`#66–103`，离他中线 −0.23/−0.17/+0.11/+0.19 身位，高约 1.07 身位）；**身上一点红都没有**。
- `assets/dnf_src/bilibili/skill-clips/07_血之狂暴.mp4`：他**整个人变成纯红剪影**（峰值 `(230,26,6)`，
  `#44–56`），普攻变双刀。

所以本作把它们当**两条技能**：

- **血之狂暴** = 架势：开关式（开一次一直在、再按一次取消），染红身 + 双刀。代码里继续占 `frenzy` 这个 id。
- **暴走** = 限时 BUFF：到点自己消失，涨攻击力 / 攻速 / 移速；读数是头顶那枚图标 + 身周的暗红竖丝。
  代码里新占 `berserk`。

那条"暗红竖丝"是本条的**取证**，而它被量错了两次，两次都是业主指出来的：

1. 第一遍用粗的红像素覆盖率量，全帧峰值只 ~1.1%、身周判为无物。换成"暗红 + 去掉身体剪影"的检测器后，
   丝线峰值 2939 px、占全帧 0.19% —— **量到的现象没错，量法太粗**。
2. 第二遍（丝线已经做出来之后）业主说「僵硬、没那么明显、红条很细、有自下往上的移动」。逐帧重量：
   - **什么都不平移**：整段稳态（`#78–#102`）里把某一列的纵向剖面做互相关，最佳位移每次都是 0 px，
     而且 0 位移处的 mse 就是最小值。**"空档逐帧在移"是上一版看走眼**，那一段是被当成丝的静态布景。
   - **是软带不是线**：`#84` y620 横切左列读数是 `21 31 62 75 64 48 27 21 13`（x736-744），
     2px 核心外带一圈平滑衰减，可见宽约 8 片像素，**而它的地板是纯 0**。折成身位是 3px，不是 1.5px。
   - **它亮，而且在呼吸**：核心 40–90、亮点到 134，对比是满的；每一列各按自己的慢拍涨落——
     同一行同一帧，左列峰值 75 时右外列只有 18。

   教训跟第一次是同一个形状：**形状、亮度、动不动，都是要逐帧量出来的**，看着像"在动"不算。

## Considered Options

> **照旧并成一条**（沿用 `CONTEXT.md` 原来的写法：「暴走」= 血之狂暴）。否。两条片子的画面差得太远——
> 一条全身纯红、一条身上一点红都没有——并成一条就得给同一个现象安两个主人，`0003` 记的那次
> 「量对了、归错了主人」正是这么来的。
>
> **把暴走也做成开关式**。否。业主的口径是"到点要续"，那是 BUFF 的手感；两招都开关式会和血之狂暴撞车。

## Consequences

- `CONTEXT.md` 里血之狂暴那条的 `_Avoid_` 去掉「暴走」，「暴走」独立成条。
- 业主在本仓库里**曾经用「暴走」叫过血之狂暴**（`0003` 引的那句「人变红是因为暴走技能」）。那处记录不改，
  但按本条用词应读作"因为血之狂暴"——**业主当时用的是旧叫法**。
- 两条片子都不含挥砍：`05` 拍到的是起手 + 头 1.3 秒（片尾 `#103` 丝线还在衰减，拍不到"丝线会不会贯穿
  整个 BUFF"），`07` 拍到的是变身那一下。以后要给它们加东西，先问"这条片子拍到了哪一半"（`0015`）。

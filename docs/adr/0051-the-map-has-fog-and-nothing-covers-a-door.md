# 地图有迷雾；贴花也不许摆在门口

**Status**: accepted（2026-10-15）。两条都来自**业主实玩那一次**的原话：

> 「我觉得很好，就是发现有的花丛遮挡住门口了，我觉得右上角的地图，带有迷雾，
> 探索地图是现在这种颜色，没有探索过的是黑的」

## 一、地图窗口：**没去过的格子是黑的**

**它推翻了 `docs/adr/0030` 里那句「录像里那张图从出现的第一帧就 12 格全画满、
包括他从没进去过的那四格」。** 那是**误读**，而且误在哪现在很清楚：

客户端的 `sprite_map_minimap.NPK :: act1.img` 里**本来就有一整族"已经去过"的亮图块**
（上一次盘点时记过：「亮色族整族没烘，脚本注释说明本作不画这个状态」）。
我们只烘了**暗的那一族**，于是把"没去过"看成了"画满"——
**十二格里本来就有'去过/没去过'两态，我们自己把它压成了一态。**

所以这一条不是"业主改口径"，是**我们当初读错了**。

**做法**：`state.dungeon.cells[i].seen` —— 挂在 `beginRoom` 上（开局那一格不经
`goToCell`，挂在那儿两条路都盖得到）。地图窗口与雷达那两副形态都按它画：
**探过的照旧画图块，没去过的盖一块黑**（连那一格的边一起盖，留缝会被读成"去过但没内容"）。
**Boss 那张红脸也跟着**只在他去过之后才画 —— 不然迷雾对它就形同虚设。

## 二、贴花也不许摆在门口

业主看到的是「有的花丛遮挡住门口了」。这件事**判定上本来是对的**——
`docs/adr/0032` 明说过「贴花不在这套里：它们不挡人也不挡门」，而那是**为了走路**说的。

可**门口那一块是给人认路的**：花丛盖上去，门拱就看不见了。所以现在贴花也过
「门口净空」那一关（手写的那条 `beginRoom` 里去掉 `box &&` 这个前置，撒的那条
`scatterProps` 里矮草/粉花/高草三档一起过）。贴花没有盒子，让位时按 0 宽算。

量过之后：**12 格一共 757 件不挡人的布景，压在门口的是 0 件。**

## 代价与未决

- **没烘客户端那族亮图块**：现在"探过"和"没探过"的差别是**图块 vs 纯黑**，
  而客户端是**亮图块 vs 暗图块**。差别在读起来是"黑得多"一点 —— 业主的口径是
  "没探索过的是黑的"，所以先照他说的做；要更贴客户端就把亮的那族也烘进来。
- **迷雾只记"去过没有"**，不记"看得见没有"（邻居格不给轮廓）。业主说的是"探索过的"，
  所以按最小的一种做。
- **贴花让位之后少摆的那几件**是直接丢掉的（试几个位置试不出来就少一件），
  一间房少个一两件，落在总数 50–90 那一档里。

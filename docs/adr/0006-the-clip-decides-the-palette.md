# 参考片决定色板，客户端预览不算

## Status

accepted（2026-09-26）。**取代 38/39 切片对色板的判断**（那两片把 怒气爆发 烘成了白金）。

## 决定

**一个技能用什么颜色，以业主给的训练房参考片为准；客户端自己的 `.avi` / 预览视频只是旁证，
两边冲突时以参考片为准，并把冲突写下来。**

怒气爆发 是第一个把这个冲突摆到台面上的技能：

| 来源 | 颜色 |
| --- | --- |
| 官方预览 `assets/dnf_src/skill-videos/Swordman-BloodBlast.mp4` | **白金/奶白**火柱 |
| 包自己的预览 `assets/dnf_effect_anim/blastblood.mp4` | **饱和红** |
| 业主点名的参考片 `assets/dnf_src/bilibili/skill-clips/08_怒气爆发.mp4` | **饱和红**，蓝通道几乎是 0 |

38/39 切片看的是第一行，于是把这一行烘成了 `(tn)` 白金板。参考片量出来的是
**环 (217,27,4) / 柱 (249,58,3)、核心 (255,61,1)** —— 这是包里**素色板**的红
（`blood-front.img` 均值 `[204,28,0]`），不是白金。包自己的预览也是红。**三条里两条是红的，
而且红的那一条正是业主指定的裁判。**

**大蹦早就在同一个岔口上，而且已经按同一条规矩走了。** `10_崩山裂地斩.mp4` 量出来是
深红 (183,25,7)，它的官方预览是橙 —— 仓库里现在是红（素色板 + `FIRE_RAMP`，见
`import_dnf_effects.py` 里 `mountainRift` 那条）。所以这条规矩不是新立的，是把 怒气爆发
拉回它。

## Considered Options

> **保留白金，记为"官方预览如此"。** 否。业主点名的就是那一段参考片；预览视频是二手来源，
> 而且它与同一客户端录出来的训练房画面彼此矛盾，没人能说清哪一个是"游戏里真实的颜色"。
> 让参考片当裁判，至少是**可复现**的。

> **两套都做，让业主挑。** 否。这会把"哪个颜色对"变成一个永久悬空的问题，
> 而 0005 已经为同类分歧定过调：**要么按参考，要么给一个能量出来的新依据。**

> **把参考片上的红当成录像偏色。** 否，量过：同一帧里称号条是 `(248,248,248)`、
> 角色中性肤色 `(146,111,91)`，没有全局色偏。

## Consequences

- **`BURST_RAMP` 按参考片自己的亮度反推出来**，而不是沿用 `FIRE_RAMP`：参考的血**饱和到蓝为 1**，
  而 `FIRE_RAMP` 的顶是白热 `(255,225,195)`，套上去会把血洗成一片浅色。
- **参考片的环和柱亮度几乎一样**（中位 (204,26,5) 对 (200,39,1)），柱的全部"更亮"都在尾部
  （p90 (254,61,12)）。所以这条 ramp 在 0.4–0.9 之间接近**平**，不是对角线——对角线那版把柱子
  烘成了 (252,86,29)，发橙。
- **实机比参考暗、比参考发蓝，这不是这一招的账。** 参考是**纯黑训练房**，本作地面是受光的蓝紫带
  （脚下实测 (32,30,49)），特效按 ~0.8 alpha 混上去，蓝通道必然被抬起来。第六十切片量过同一件事
  （收招的对比度差在竞技场地板上，不在招式里），**不要靠在招式里加红去补** —— 那会让它在暗处
  比参考还红。
- **训练房那一套技能里，`(tn)` 板仍然是有些技能的正解**（崩山击的橙火就是参考片量出来的橙）。
  这一条是"以参考片为准"，不是"一律用素色板"——谁再动哪一行，先去量那一行的参考片。
- **业主玩的时候开着血之狂暴才对得上色**：参考片里那身红是架势的（`docs/adr/0004`）。

# HUD 照录像到什么程度：**边距照它、组织照本作**，新加的那三样按它的位置摆

**Status**: accepted（2026-10-14）。业主在 grill 上答 **Q13 选 b**：
「只挪边距、不挪组织」；以及 **Q9「都做」**（消息日志 / 战斗评分 / 脚下标记 /
开场插图与关卡名 / 结尾宝箱与评级 / Boss 登场）与 **Q8 选 b**（金币进结算）。

量自 `dnf-dungeon-videos/00001-幽暗密林.mp4`。**录像像素 → 本作画布**要过两段：
先减掉游戏画面在帧里的左缘（**240**），再乘 **0.5**（1440 → 720），最后加**世界窗口的
左缘 120**。所以 `画布x = (录像x − 240) × 0.5 + 120`、`画布y = 录像y × 0.5`。

## 决定

**一、边距从世界窗口量，不从画布量。**

世界收成居中的 4:3 之后（`docs/adr/0040`），画布左右各 120 px 是黑边：靠左靠右的 HUD
若还按 0 与 960 摆就会摆进黑边里。录像的 HUD **一律压在游戏画面之内** —— 它的地图窗口、
目标条、日志，没有一样画在黑边上。所以 `HUD_LEFT = VIEW.left`、`HUD_RIGHT = VIEW.left + VIEW.width`，
靠左的东西 `HUD_LEFT + m`、靠右的 `HUD_RIGHT − m`。

**以 480 居中的东西一个字不用改**（120 + 720/2 = 480）：提示条、强化卡、胜负画面、
地区地图、标题、房名牌全在这一档。

**二、组织仍是本作的。**

玩家卡（血/蓝/经验三条）留在左上、技能栏仍在左下、配速字与房间卡都在原处。
录像的左上角只有"当前目标"那一块，它把血蓝摆到底部做成两颗球、技能栏只有 6 格 —— 而
本作有 12 格技能、一条经验条、配速与房间卡，照搬会多出一排空槽。**这条线是同一句：
录像里有的照它摆，本作自己的留着自己的组织。**

**三、新加的三样按录像的位置摆。**

| | 录像（画布坐标） | 用途 |
| --- | --- | --- |
| **消息日志** | 左，x≈145–350，y≈90–250，最多 8 行 | 掉落与事件的收口（`获得[破旧皮革]1个` 那一类） |
| **战斗评分** | 右，x≈645–700，y≈350–415，4 行 | 操作 / 技巧 / 被击数 / 评分 |
| **脚下的黄绿椭圆** | 跟着他，约 67×22 画布px，亮心 `(155,250,78)` | 只有玩家有，怪没有 |

## 战斗评分：名字照录像，公式是本作自己的

录像写的是 `85% 操作 / 57% 技巧 / 15 被击数 / S 评分` —— **名字与排版能照抄，公式抄不到**
（那是加密的 `Script.pvf` 里的事）。本作的规矩是「一个读数要么真讲一件事，要么别画」
（`docs/adr/0036` 就是照这条把 `ALERT!` 压下来的），所以四个数都从本作**已经有的**东西里数：

- **被击数** = 这一局挨了几下（**计数，不是伤害**）。需要新记一个 `stats.hitsTaken`。
- **操作** = **出手的命中率**：出手数（按一次普攻、放一个技能，各算一次）里有多少次真的打中了。
  需要 `stats.swings` 与 `stats.swingsLanded`。**它不数"打中了几个"** —— 一刀扫中三只
  不该把命中率顶到 300%。
- **技巧** = **连击保持**：平均连段长度 ÷ 基准，封顶 100%。连段 = 相隔 2 秒以内的连续命中。
  需要 `stats.comboChains` / `stats.comboHits`。**基准取 6** —— 那是本作自己的数
  （普攻一套三段，接一个技能就是 6），**实玩之后调它，别把它当成量出来的**。
- **评分** = `100 − min(50, 被击数 × 4) − 超时扣分 + min(10, (等级 − 1) × 2)`，
  其中超时扣分 = `max(0, (用时 − par) / par × 30)`，**par 取 300 秒**
  —— 量自录像：它从进副本（56.9 s）到 Boss 倒下（约 330 s）是 **约 300 秒**。
  档位 **S ≥ 90 / A ≥ 75 / B ≥ 60 / C 其余**。

**这几个常数都是本作的口径，不是量出来的**；`操作`/`技巧` 那两个百分比的底是设计。
这一点要写在界面之外的注释里，免得半年后被当成录像里的数。

## 代价与未决

- **日志要能拿到"事件"**：现在的事件是散在 `stats` 与一次性 effect 上的，日志需要一条
  自己的队列（谁在什么时候往里面推一行、一行挂多久）。
- **脚下游标与影子不是一回事**：本作有影子，那个椭圆是**亮标记**。两个都画。
- **评分的常数一个都没验过**（par 300 s、每次 −4、基准 6）：等业主实玩第一局再调，
  ADR 里这一节就是改它的入口。

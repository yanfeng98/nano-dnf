# 门口净空按**美术矩形**过，四扇门都过，花草贴花也过

**Status**: accepted（2026-10-18）。业主：「第一排第三个房间里通往第一排第四个房间，
有杂草盖住了门口」。

## 根因

净空从一开始是按**碰撞盒**写的：`blocksDoorway` 一拿到 `propBox()` 为 null 就
`return false`。花草、贴花没有盒子（它们不挡路），于是**在四扇门前全部免检**；
唯一能管到它们的是 `blocksDoorLane`，而它只查 N/S 门、只比中心 x，而且手写件
根本不走它。`docs/adr/0051` 说「贴花也过门口净空」——那次改的是 `beginRoom` 里的
一个 `box &&`，真正的早退在 `blocksDoorway` 内部，**那次修正是空操作**。

默认种子 20260915 精确复现：第一排第 3 格 `(2,0)`「倒木小径」往东到第 4 格；
东门门拱上有一丛 `grass`（重叠 18×54 px）和几件贴花。扫 12 格 757 件无盒布景，
**71 件压着门拱**（E 33、W 35、N 3）。

## 决定

- `src/core.js` 新增 `PROP_ART`（无盒布景的 ink 尺寸，和 `render.js` 的
  `SCENE.pieces` 对得上）与 `propArtSize(piece)`；`propBox().ink` 也跟着倍率缩。
- `blocksDoorway` 拆成两条：**地面**那条只在有盒时查；**门拱美术**那条对
  **所有**布景都查，四个方向一视同仁。无盒件不查地面（它们不占身位）。
- `beginRoom` 的手写件和 `scatterProps` 的撒点件走同一套；手写件压门时按
  **美术半宽**挪，挪不开才丢。
- 门拱盒子仍用偏保守的未缩放 `GATE_ART`（比实际 0.8 倍的门大），宁可多让一格。

回归测试覆盖默认种子 12 格的**所有** props，并单独钉住业主报的那一格。

## 代价

- 门口附近的草/花会被挪走或丢掉一些（默认种子 71 件里大部分能挪，少数丢弃）；
  这是「门是给人认路的」那一条的代价（`docs/adr/0051`）。

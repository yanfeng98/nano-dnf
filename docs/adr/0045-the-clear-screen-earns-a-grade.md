# 通关那一页：一枚评级徽记与那只箱子

**Status**: accepted（2026-10-15）。业主在 grill 上答 **Q9 要战斗评分与结尾宝箱**、
**Q8 选 b**（金币进结算）。

量自录像的 333.4-357 s。

## 决定

**一、评级与总分画在战绩表旁边。**

录像那一页是**逐行淡入**的：`战绩` + `总分 85 / 140` → `操作 60`（金）+ 金进度条 85%
→ `技巧 40` + 条 57% → `被击数 -15`（红）→ 左边一枚**金色大 S 徽记** + `评分`
（每行差 0.8 秒）。**本作的战绩表本来就在这一页上**（种子/用时/等级/强化/击杀/承伤），
所以这里补的是**那枚评级徽记**与**那只箱子**。

**徽记用的是客户端自己的图**：`sprite/interface2/ui/comboeffect/dungeon_rank.img`，
17 帧里**奇数帧是彩的**（量过：1=橙 SSS、3=SS、5=黄 S、7=绿 A、9=薄荷 B、11=蓝 C、
13=靛 D、15=紫 F；偶数帧是同字形的白版，末帧是爆闪）。
**按 1:1 画、不缩** —— 那一帧 169×106 是连辉光一起量的，字形只占其中一小块，
缩了就成了一个看不清的小记号。

**二、箱子只在**赢**的那一页上。**

录像里它是 `奖励` 那一页的：红木金边宝箱坐在蓝色魔法阵正中，打开时**迸出的是
白/青的光爆**（不是金币，金币只在领奖框里以文字出现），然后翻开四张金卡背。
本作烘的是**合盖那张卡面**（`sprite_interface2_reward_ver2.0.NPK` 的 `reward_ver2.img`
第 36 帧，153×97）。

**三、位置是本作自己的。**

录像那块板在 4:3 的正中，本作这一页已经排满了（表 + 链接 + 提示），所以徽记摆在表的
左边、箱子摆在右边 —— **照录像的内容，不照它的排布**（与 `docs/adr/0041` 那条同一句）。

## 追记：逐行与开箱都做了（2026-10-15）

业主说「继续」之后补上的两段，**表的仍然是录像**：

- **逐行淡入**：`总分` → `操作` → `技巧` → `被击数`（红）→ `评分`，每行隔一档；
  徽记跟"评分"那一行同时到。**间距从 0.8 秒压到 0.45 秒** —— 录像那 17 秒的谢幕
  配一局 3 分钟的副本太长，这是本作自己的取舍。
- **开箱那两下**：箱子带着一圈蓝魔法阵**弹进来**（1.25 → 1.0）→ **白青爆闪**
  （0.35 秒，亮起再落下）→ 领奖框。
- **领奖框里那行金币读 `stats.gold`**：**这一局从地上捡起来的总数**（业主 Q8 选 b）。
  这是掉落那一条（`docs/adr/0042`）与结算这一条接上的地方。

计时器是 `state.finishedAt`：结束那一刻钉在 state 上。结束之后 `state.time` 还在走
（战绩读的是快照），所以这一页的每一拍都从它数起。

**四张卡仍然没做**，而且这一条改了性质：录像里那是"从四张里选一张奖励"，本作的奖励
回路本来就是**打怪掉东西 + 清房翻三张卡**，再开一套"选一张"是**另加一个回路**，
不是补一帧。要做先得回答"它给什么"。

# 领主血条是一条 1068 长的整条，不是 278 绿条 + 一条橙色 ALERT

**Status**: accepted（2026-10-18）。业主：「领主血条不对和参考视频有差异」。

## 重看录像量到的

`dnf-dungeon-videos/00001-幽暗密林.mp4` 的领主战（约 226–329s，游戏画面 1440×1080）：

- 目标面板是**一条** 1068 长、59 高的条（`x 328..1396`），头像 80×80 在左。
- **绿色 `#8FC700` 是 HP 填充**，从右端退；橙色 `#FA8000` 是这条里**没被填满的空槽**，
  上面两行 `ALERT!`。t=232s 绿 776 / 橙 244；t=250s 绿 276 / 橙 790。
- 绿条见底后换**红相位 `#DB0000`**；红条同样从右端退。
- 类别牌与名字**直接画在条内**；没有单独名字行，**没有半血竖线，也没有「· 狂暴」**。
- 掉血处有一块 20–45 视频px 的浅色块原地褪色（约 0.8s）。

**`278` 是 t≈250s 那一帧的绿色剩余量，不是条长。** `docs/adr/0043` 把它当成了整条。

## 决定

- `TARGET_PANEL.bossBar = 1068`、`bossBarH = 59`、`bossPortrait = 80`；
  条内先画橙色 ALERT 空槽（只在绿相位、交上手之后），再压 HP 填充；
  类别牌/名字画在条内；去掉半血竖线与「· 狂暴」后缀（狂暴仍是玩法）。
- **面板位置不照录像顶到最上面**：本作左上角有玩家卡（y 14..110）与配速行（y 128），
  录像的玩家 HUD 在底部、那里是空的。所以内容与形状照录像，整块挂在 y=150
  （`TARGET_PANEL.bossY`）——和 `docs/adr/0041`「照内容不照排布」同一条。
- 头像用**参考录像 t=250s 目标框自己的 80×80 正脸**（`assets/boss_portrait.png`）；
  战斗精灵的侧身头在 40px 下只剩肩膀（详见追记二）。
- 杂兵那一块条不变（红条、独立名字行、278/362 那套按杂兵量）。

## 代价

- **两条血是"一条池、两段条"**（2026-10-18 业主复看后明确：「原视频中是两条血，
  才换颜色的」）：Core 仍是一条 120 的 HP 池，二阶段在 `hp <= maxHp * 0.5` 触发；
  条按两段画——绿色第一条从满血走到 50% 见底，红色第二条从满格再走到 0，
  两条各占整条 1068。颜色变化就是"换到第二条血"，总血量与战斗长度不变。
- 参考里红条那段「从右往左填满」的过渡没有做：本作第二条一出现就是满格。

## 追记（2026-10-18）：条加粗

业主复看后说「boss的血条应该是粗的」。宽度仍是录像的 1068，**高度 59 → 70**；
绿色/红色填充**从顶到底**（原来上下各让 3 录像px 的边框，59 高只填 53）。
橙色 `ALERT!` 空槽仍在右端。没有把 HUD 整体放大——只加厚这一条。

## 追记二（2026-10-18）：目标框头像用**参考录像自己那张 80×80**

业主复看两次：「领主牛头的血条头像不对」「还是有差异」。战斗精灵的牛头是**侧身低头**，
切到 40px 只剩肩膀和鬃毛；选关卡片上的 3/4 正脸虽然接近，细节仍和录像不是同一张。

最后直接用**参考录像 t=250s 的目标框自己**：裁 `(248,86,80,80)`，烘成
`assets/boss_portrait.png`（`assets/import_reference_portraits.py`）。它是 80×80 的
正脸，连参考里的金属框和四角红铆钉一起裁进来了，所以渲染走这一路时**不再自己描框**。
没有这张图时才回落到选关卡片的正脸，再没有才用战斗精灵。出处与 觉醒插画 同一条
（参考片是业主给的，客户端里没有单独的正脸分件）。

# 掉落在**地上**：名牌、自动捡、捡起来才给经验

**Status**: accepted（2026-10-14）。业主在 grill 上答 **Q8 选 b**（金币进结算）、
**Q12 选 a**（**捡起来才给经验**）、**Q9 要左边那栏日志**。

量自 `dnf-dungeon-videos/00001-幽暗密林.mp4`（1920×1080、265 px = 1 身位）。

## 决定

**一、怪一死，地上摆一块写着物品名的名牌。**

不是一个图标，是一块**深色半透明底 + 2-3 px 亮边的圆角牌**，里面一行
**浅青 `(126,210,216)`** 的字（字高 27 视频px，牌宽随名字长度：`诺顿的新手HP药剂`
那块是 263×45）。**框的颜色会变**：脚下那件（现在就收得走的）换**黄绿亮边** ——
录像里同一件东西在 245.8 s 是黄绿边、249.0 s 不在脚下时是白边。那是"收得走"的读数，
所以它跟判定**共用同一个半径**，不另编一个给眼睛看的数。

**二、走过去自动收，没有拾取键。**

录像全程没有按键动作。半径按**身体间距**量（`CONTEXT.md`「身体间距」）——
和"够不够得着"同一把尺子 —— 深度也要在同一档上（`DEPTH_REACH.melee`）。
精确半径量不出来（地上叠了好几件，分不清哪条牌子对应哪件），**这是本作自己的数**。

**三、收的那一刻三样一起发生。**

牌子没了、原地浮一行**亮绿 `(105,198,46)`** 的 `+40 Exp`
（上浮 66 视频px 用 0.3 秒、然后停住、活不到 1 秒）、左边日志加三行
（`获得[X]1个` / `获得40点经验值` / `获得38金币`）。

**四、经验挂在"捡"上，不挂在"杀"上**（业主 Q12 选 a）。

录像里那行 `+40 Exp` 就是名牌被收走那一刻浮出来的。于是 `damageEnemy` 的死亡那一支
**不再 `grantXp`**，改 `dropLoot`；`grantXp` 挪进 `collectLoot`。掉落点就是它倒下的地方，
够得着。**金币**累计进 `stats.gold`，结算页读它（业主 Q8 选 b）。

**五、名字全部来自录像那份日志。**

`破旧的皮革 / 碎片 / 哥布林毛皮 / 生锈的铁片 / 煤尘 / 哥布林手骨`（白名）与
`最下级硬化剂 / 炉岩炭 / 冰冻水 / 诺顿的新手HP药剂 / 古老的法杖`（青名）——
**白名与青名两档是照录像分的颜色**。一件掉落由 `(种子, 怪的编号)` 决定，
**不走 `nextRandom`**：那一条是敌人抖动与血球共用的，动它整段演示都会变
（`docs/adr/0037` 在这一条上踩过一次）。

## 左边那栏日志

量出来的四条：**没有底板**（字直接描边压在世界画面上）、**8 个固定槽位**
（首字离游戏画面左缘 45 视频px、行距 33.7、字高 26-27）、**不淡出、不滚动、
没有存活时间**（满了挤掉最上面那行）、**四档颜色** —— 经验/金币土黄、白名道具白、
蓝名道具青、状态消息橙。它**跨房间留着**。

**首行比录像低 44 px**：录像那一带上面只有一块目标条，本作那里是**玩家卡与配速字**，
照录像摆会压在它们身上（抓帧见 `tests/browser/capture-hud.mjs`）。组织是本作自己的
（`docs/adr/0041` Q13 选 b），所以让到它们**与"当前目标"条**下面，左右边距仍是量的那个。

## 代价与未决

- **牌子在地上的存活上限没量到**：本作是"换房才清"，与「出门就留在门外」同一条。
- **录像结尾那口宝箱里的奖励卡**没有做，见 `docs/adr/0045`。

# 两段录像优先于此前为本作作出的偏离

2026-10-29，业主在 grill-with-docs 中明确选择：
「全部严格照录像，包括重审此前确认的规则」。

因此默认地图、迷雾、两排技能、为了自动通关调整的参数、额外城镇布局与结算组织等，均重新接受两段原始录像检验。旧 ADR 中的 accepted 记录保留为历史，不再作为允许偏离录像的理由。0067 的默认方图和立即撤门板也在重审范围内。

参考分别为 `00001-幽暗密林.mp4` 与 `00002-幽暗密林深处.mp4`，当前位于业主指定的 `~/luyanfeng/dnf-素材`。画面与可观察动作以所属录像为准，不能把一关的观察直接套到另一关。

这一选择会牺牲现有的部分便利功能和为机器人调过的节奏，并要求重新验证按键通关；不能以机器人测试通过替代录像一致性。录像没有展示的隐藏数值、侧房与交互，记录为未知，不编造“录像原值”。素材仍从业主本地客户端寻找，缺件要明确记录。

执行顺序是先建立可追溯差异清单，再按空间关系和通行、人物与战斗、界面与城镇结算逐批修复。总账为 `../reference-video-audit.md`。每批分别记录原帧、回归、修正后同机位图与尚未解决项；业主实玩确认前不标整体验收。

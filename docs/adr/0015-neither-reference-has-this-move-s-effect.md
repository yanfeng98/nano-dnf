# 这一招的两条参考片里，都没有它自己的特效

## Status

accepted（2026-09-30）。这是本仓库第一次**一条参考片只管一半**。

## 决定

1. **身体照训练房那条**（`skill-clips/04_嗜魂之手.mp4`），**特效照业主指的实战那条**
   （`BV1oUDLBaEaK.mp4` 76.633–77.667s，切为 `E01_嗜魂之手-实战.mp4`）。两条各缺一半，见下。
2. **整招 1.0333s = 实战那条自己的 31 帧**：`duration` 1.0333、`grab.hold` 0.567、
   `hitAt` [0.129, 0.742]。
3. **`invuln` 罩满整段施法，`superArmor` 压在下面。** 业主点名的两条，按他说的顺序：
   「这个技能不能被打断吧」→ 霸体；「这个技能要无敌」→ 无敌。
4. **`blood.img` 是同一份素材用在两端**：抓取命中（第 4–7 列，小）与喷血（第 23–30 列，四倍大）；
   中间那半秒（第 8–22 列）是 `blood-dodge.img` 罩在**被抓的目标**身上。

## 为什么

**训练房那条零特效。** 三种口径都验过：96 帧拆连通域找「离角色 ≥12px 的独立块」，**96 帧全是 0**；
唯一的非角色墨迹是 #1–#6 那 2151px 的上一招残影（与 `03_死亡抗拒` 的末帧 IoU 0.865）。
抓取类技能没有目标就不触发 VFX，它只能给**身体和节奏**。

**实战那条那团粉红的血不是这一招的。** 业主：「这个血是血之狂暴的特效，不是嗜魂之手的，
当有怪物受伤时，会有血球给红眼回血」—— 而仓库自己的 `dnf_effect_picks.md` 早就把它记成
`frenzy/blood-stone-0.img`「怪物身上吸的血球」。被抓住的那只正在挨打，所以它身上冒出了回血球。

**所以"照参考"在这里走过两次弯路，两次都是抄了别人的东西**：先照那团回血球做了一颗球，
再照一团火做了喷血（"那团火"其实是 `blood.img` 旁边另一条 319px 的流体爆）。最后是
**业主指着候选表点名**才收的口：喷血 = `blood.img`（第 1 行）、吸住 = `blood-dodge.img`（第 3 行）。

**无敌那一层是业主自己提的，而且它是这个问题的兜底。** 霸体已经够挡住"挨打不断招"，但业主两次说
「还是被打断」而我在真浏览器里复现不出来 —— 无敌把 `damagePlayer` 在**碰任何东西之前**就返回 0，
于是"怪物用什么招都结束不了这一招"变成**保证**，不是调参。代价是这一招期间**一点伤害都不吃**，
那是玩法层面的事，写在这里备查。

## Consequences

- **`assets/measure_row_against_clip.py` 量不了这一行。** 它的「找施法者的靴子」是照黑底训练房写的，
  实战帧有雪地背景、怪和伤害数字。这一行的落位是用一段专用脚本解的（窗口声明成对数、
  解完之后逐层复量，残差 ≤0.6px）。**把那条尺做成能吃实战帧的，是下一片的事。**
- **`EFFECT_CLIPS` 那张表进 `extract_bilibili_skills.py`。** 业主按钟点指的参考不属于
  「自动按标题切的巡演」，它是第二类，在脚本里分开记、在 `INDEX.txt` 里分开列。
- **`血之狂暴`开着的录像里，红的东西要先问归谁。** 红身归架势（`0003`/`0004`），
  怪物身上的回血球归 `frenzy` —— 这一片量的那条片子两样都占着，能用的只有"伸出去的那只手
  罩住的目标"这一层。
- **下一片的第一句话应该是「这条片子拍到了这一招的哪一半」。**

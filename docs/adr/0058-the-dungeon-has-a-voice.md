# 地下城有声音：客户端原音、每种怪三声、玩家每招一声

**Status**: accepted（2026-10-19）。业主在 grill 上说「每个怪物和角色有声音」，
选了“玩家普攻 / 受伤 / 死亡 + 每招语音 / 效果音、每种怪的攻击 / 受击 / 死亡叫声、
保留现有合成音往上叠”，并追加「脚步、森林环境声、怪物脚步声、音乐轻微 ducking 全都加」。

## 素材

客户端 `SoundPacks/` 里有原音：

- 哥布林：`gbn_dmg_01..04`、`gbn_die_01..02`、`gbn_thw`、`gbn_talk_01..05`、
  `gbn_comm`、`gbn_scared`、`gbn_spin` 等；
- 牛头：`tau_dmg_01..03`、`tau_die`、`tau_axeswing`、`tau_crash`、`tau_roar`、
  `tau_rush`、`tau_breath`、`tau_comm`、`tau_talk_01..02`、`b_taubeast_01`、`b_tauarmy_01` 等；
- 玩家剑士：`sm_atk_01..03`、`sm_dmg_01..03`、`sm_die`、`sm_jump`、`sm_blood`、
  `sm_boongsan`、`sm_blood_rave_atk` 及各技能 effect；
- 环境：`amb_forest_*`、`amb_rain_*`、`effect/amb/grass_pass` 等。

## 决定

- **来源**：客户端原音，和音乐 / 美术同一条来路；进 `assets/sfx/` 与 manifest，
  不在运行时合成（现有合成音只保留为“没有对应原音时的兜底”）。
- **玩家**：普攻、受伤、死亡、跳跃、每个技能的语音 / 效果音；技能语音只在起手那一帧播一次。
- **怪物**：每个兵种至少 **攻击 / 受击 / 死亡** 三声；同族多帧随机取一条；
  同一只怪 0.15–0.3 秒内不叠同一类声音，避免十只哥布林同时叫。
- **环境**：玩家脚步声（草地）、森林环境声循环、怪物脚步声（轻）、雨声（见 `0057`）。
- **混音**：按屏幕 x 做左右声像；语音响起时音乐**轻微 ducking（约 −4 dB）**；
  雨 / 森林环境声压在音乐下面；总音量沿用 `M` 静音与 `audio.master`。
- **事件来源**：声音从 `Core` 的确定性事件队列出（攻击、受击、死亡、脚步），
  由 `main.js` 消费播放；不在渲染层猜状态，保证可测试、可回归。

## 被否掉的

- **只用合成器**：业主明确要“每个怪物和角色有声音”，合成器做不出哥布林 / 牛头的音色。
- **每只怪各自一套独立音色**：客户端本来就按族分；同族多帧足够，
  按个体分会让同屏十只变成十套素材，收益小、体积大。

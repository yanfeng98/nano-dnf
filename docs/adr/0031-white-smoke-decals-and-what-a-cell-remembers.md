# 死是白烟不是血块；花草是贴花；一格记着它碎过的桶；地面那两块黑本来就是没人画

**Status**: accepted（2026-10-10）。业主实玩 `docs/adr/0030` 那一片之后报了四条，
在 grill 上逐条定掉，最后一句是**「全部按照推荐」**：

1. 「存在黑色阴影」—— 截图里草地上横着两块黑；
2. 「人和草的图层不对」—— 人站在草上时**草把人遮住**了；
3. 「水桶打破了，但是下次再次进入这个房间，木桶又出现了」；
4. 「怪物死亡现在是一滩血，感觉和视频不匹配」。

参考片仍是 `assets/dnf_src/bilibili/BV1d24y1P74G.mp4`。第 4 条的证据帧量在
`/tmp/deathstudy/`（视频侧 `meas-69.45.png`、`meas-156.10.png`、`meas-246.45.png`、
`meas-328.50.png`；我方 `burstzoom.png`）。

## 决定

**一、地面那两块黑不是画上去的，是"没人画"的地方 —— 补上。**

客户端那三张地面条（`sprite_map.NPK :: sprite/map/02tile0{1,2,3}.img`）**顶角本来就是
透明的**：原图 alpha=0（`02tile01.img` 有 6.6% 的像素透明，整行第 0 行都在里头），形状
是照着这一套房间美术里树的外轮廓切出来的。原版游戏靠 `obj` 层的树干/草丛把它填住；
本作把那些树的底座摆在地面带的上沿（`backY`），差三四十像素填不到，于是缺口里透出来的
是**画布底色**（`index.html` 的 `#05070f`，再被 `drawVignette` 压一层）= 两块硬边死黑。
量法：把画布截下来合到洋红底上，黑块整块变洋红（alpha≈0，不是黑颜料）；黑块逐行形状与
`tile1/2/3` 的透明角**逐像素吻合**（`/tmp/probe/verify_wedge.py`）。

修法是**烘图时把缺口补掉**：`assets/import_dnf_scene.py` 的 `close_top_gaps()` 把地面条
每一列里透明像素用它**正下方**的颜色填上（往下到上的一级级边缘延展），于是缺口里露出的
是它自己的地面往上涨了一块。验：十二格逐格扫整张画布，全屏只剩 1–2 个孤立透明像素、
都在第 506–536 行技能栏底下（看不见）。

**二、长在地上的花草是「贴花」：草不遮人。**

`SCENE.decals = [grass, grassFlower, sprout, flower, bush]` 这一档**不进**"站着的东西"
那个按身位排的队，一律画在地面之后、所有人之前 —— 人踩在草上面。木桶、石头、树、树桩、
柱子那些**立起来**的东西仍然按身位排（`docs/adr/0030` 那套没动）。

**这一条与录像不一样，是业主的选择，不是量出来的。** 录像里客户端自己就是按身位排的：
105.1s 那丛草接地比他的脚靠前 19 游戏像素，草叶压在他的小腿上；100.0s 他在草前面 55 像素，
就是他压着草。我们原先也是这么排的 —— 他报的那一处，草只比人靠前 **3 像素**（几乎同一排），
读起来像 bug。摆出两条路（照录像 / 贴花）之后他选了贴花：**他的眼睛大于尺子**。

**三、一格的记性：碎过的桶不会因为再进一次门就长回来。**

一局里 `state.dungeon.cells` 一直在（换房只改 `state.cell` 这个下标），所以"这一格记着
什么"有地方放：`cell.cleared`（清空过没有，门开不开、还刷不刷怪）现在多了 `cell.props`
（这一格的布景对象，摆了就不再重摆）。木桶碎过的 `broken`/`gone` 就记在这批对象上。

- **不记的**：地上的掉落物（出门就留在门外）、**没清完**那些怪的血量（重进满血重来，
  那是 DNF 的规矩）。
- 顺手修了同一族的漏：换房时 `state.effects` **不再带过去**。特效是按它出生时的 x/z 画的，
  上一间房那个死亡爆闪本来会在新房的地上接着烧半秒。

**四、死是白烟，不是血块 —— 0030 第六节看错了。**

刷一遍录像的四次击杀（69.5s / 156.1s / 246.0s / 328.2s）量出来的是：

- **主路（每一次击杀都有）**：尸体先躺住 → 一团**白烟**盖上来 → **烟散的时候尸体一起没**。
  烟 58x36 ～ 113x42 游戏像素、0.35–0.6 秒；**地上什么都不留**。
- **青白色圆爆 + 飞出来的红球**只在 246.0s 那一次拍到：先烟（0.35s），再圆爆 100–130 像素、
  亮 0.1–0.3 秒。**那些红球不是血**：它们圆润、有高光、有名字条（「诺顿的新手HP药剂」），
  而且 245.0s —— **那次击杀之前** —— 就躺在草地上了。它们是**怪掉在地上的东西**。
- **Boss（328.2s）**：身体塌下去 2 帧 → 一大团白云 **233x130 游戏像素、约 0.95 秒**，
  底下带几块土色碎块，**没有红**。

所以：`DEATH = {lie: 0.2, smoke: 0.5, bossSmoke: 0.95, burst: 0.1}`，
`updateDeaths` 一条时间线走完（`dying` 从 `lie + smokeLife()` 数到 0，途中滑过
`smokeLife()` 那一刻推一条 `deathburst`，数到 0 时尸体才撤）。烟的素材是客户端自己的
`monsterdieblood`（一张白色的不规则云，原版把颜色交给引擎挑）。**红肉块那三帧
（`hiteffect/bloodlarge`）从烘图里删掉了**，`deathChunk1-3` 一起没了。

**哪几档带圆爆**：录像里六次击杀只拍到一次，触发条件没量出来（是怪的种类？是致命一击的
招式？）。本作给了一个明确的分档：**普通怪只有烟；精英与 Boss 多那一团圆爆**。

## 为什么必须这么做

**四条里有三条是"我们按自以为读懂的录像画，业主一眼看出不对"。** 第 1 条我们以为那是
阴影，其实是画布漏底；第 4 条我们以为那是血块，其实是掉落物。两条都不是审美问题，是
**没量干净**：只量了一次击杀就把它当成所有击杀的规矩（0030 第六节），只看了黑块的形状
就没去看它的 alpha。

**"草不遮人"这一条是例外**：它不是量出来的，是业主拍板要一条与录像不同的规矩。记在这里，
是因为下一片的人一定会看到录像里草遮人，然后以为代码写错了。

## 被它推翻的

- **`docs/adr/0030` 第六节**「怪物死亡 = 倒地 → 青色圆爆 + 9–14 块红肉块」：整套换了。
  那 9–14 块**红肉块**的素材（`hiteffect/bloodlarge` 第 1–3 帧）从 `assets/import_dnf_scene.py`
  的 `PIECES` 里删掉，`src/render.js` 的 `deathChunk1-3` 跟着删；`DEATH.chunks` /
  `DEATH.chunkCount` 两个数没了。
- **`CONTEXT.md` 的「血块」** → 改成**「死烟」**。
- **`beginRoom` 每次都从房间规格重造布景**（`state.props = spec.props.map(...)`）→
  改成一格摆一次，挂在 `cell.props` 上。
- **`state.effects` 跨房间活着** → 换房清空（本房间的名牌在清空之后才推，所以它还在）。
- **「人和草按身位排」** → 花草改成贴花（见决定二，这是业主的选择，不是量出来的）。

## 代价与未决

- **贴花那条与参考片不一致**（上面说了）。哪天他觉得"人走到草丛后面该被遮住"，改回来
  只是把 `SCENE.decals` 那一档放回排序里。
- **圆爆的触发条件没量出来**：现在按"精英与 Boss"分档，是**本作的读法**，不是从录像里抄的。
  录像六次击杀里那一次到底是哪种怪、哪一击，没量到。
- **Boss 那团云盖不满整个身体**：量到的云是 233x130，而牛头巨兽躺下来比它宽 —— 头尾会露在
  云外面。录像里也是这样（云盖住躯干）。
- **没量到的**：白烟/圆爆/红球三种效果的音效；Boss 那团云是淡出还是缩小（只测到
  329.17→329.23 亮像素 1494→127）。
- **南门仍几乎看不见**（`docs/adr/0030` 同款未决），**怪仍不会绕木桶**。
- 补地面缺口是**烘图期**的做法：换一套 `tile`（比如别的关卡用 03/04 套）时要让
  `close_top_gaps` 也过一遍 —— `main()` 里按 `name.startswith("tile")` 挑，新加的
  `tile*` 自动在里面。

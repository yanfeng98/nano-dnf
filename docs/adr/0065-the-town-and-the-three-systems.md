# 城镇与三套系统：任务、物品、商店

**Status**: accepted（2026-10-22）。业主在 grill 上选的是：新增城镇、8 个 NPC、
任务/聊天/物品三套系统做全、装备数值本片归零、存档跨局保留。
这篇定城镇与系统的骨架；HUD 见 `ADR-0064`，深处内容见 `ADR-0063`。

## 一、流程与死亡

   标题 → 城镇 → 城门 → 地区地图选关 → 副本
   副本失败/死亡 → 回城镇：任务与背包进度保留，这一局的副本进度清空

城镇是任务、商店、存档的落脚点；没有战斗。死亡回城而不是原地重试，
才能让“整理装备再进”成立。地区地图仍然存在，城门是它唯一入口。

## 二、城镇

- **美术**：客户端 `sprite_map_grenselos.NPK` 的完整城镇套（far 640×219、
  mid 895×258、grtile 224×244、6 种房屋、树、墙、桥、电线杆、沙袋、木箱、碎石）；
  门从艾尔文防线套借 `elvensgate`/`gatedoor`/`gatelight`，混用前先做预览对照。
  BGM 用客户端 `forest_town.ogg`。
- **规模**：约 **30 身位宽、4 层视差**（远景/中景/地面/物件），镜头跟随、
  沿用副本的死区与深度轴。
- **无战斗**：安全区，技能不可用、不显示伤害数字。
- **8 个 NPC**（entry 名到职能的对应先做带标注对照表，业主确认后写死）：

  | 职能 | 客户端 entry |
  |---|---|
  | 主线任务 | `npc_sr.img`（赛丽亚） |
  | 支线 1 | `npc_minet.img`（敏泰） |
  | 支线 2 | `npc_gsd.img`（GSD） |
  | 商店 | `npc_kanna.img`（卡妮娜） |
  | 仓库/重置 | `npc_brownie.img`（布兰妮） |
  | 铁匠/分解 | `npc_sin.img`（辛达） |
  | 装饰 | `npc_guardian.img`（守卫） |
  | 装饰 | `npc_guardian_captin.img`（守卫队长） |

- **装饰 NPC 有闲聊，而且只讲真实存在的事**：键位、地图与门、领主的扑跃/光束与应对；
  **不提不存在的元素弱点**。
- 铁匠只做**分解/回收**：把不要的装备拆成材料，材料能在商店卖；不做强化、不做修理。
- 仓库兼**重置存档**。

## 三、任务系统

完整系统（接取、分支、交付、奖励、任务日志分类），但首片只铺**1 主线 + 2 支线**：

| 任务 | 目标 | 奖励 |
|---|---|---|
| 主线 | 通关幽暗密林深处（击败暗咒猫妖） | 金币 + 一件武器 |
| 支线 1 | 击杀 10 只猫妖 | 金币 + 消耗品 |
| 支线 2 | 打碎 5 个木桶/宝箱 | 金币 + 消耗品 |

- 三个目标分别接“通关”“击杀计数”“可破坏物计数”，都是已有机制，不新造统计。
- 任务在城镇 NPC 处接取/交付；地区地图上不摆 NPC。
- 任务日志用客户端 `questwindow.img`；页签与分类按这个窗口的旧式布局。
- 击杀 10 猫妖的支线在深处名册确认后按实际房分布复核，必要时调数字。

## 四、物品与商店

- **10 个装备槽**（武器、上衣、下装、头肩、腰带、鞋、项链、手镯、戒指、辅助装备）。
- **4 类物品**：消耗品、材料、装备、任务物品。
- **装备数值本片全部归零**：有槽位、有稀有度、能穿能卖，但加成为 0；平衡另开一片。
- 消耗品：**HP 药、MP 药**（MP 见 `ADR-0064`）；商店只卖消耗品与回收材料，**不卖装备**。
- 装备来源：主线奖励一件武器、精英/Boss 低概率掉落、任务奖励；铁匠分解多余装备。
- 背包用 `iteminventorywindow.img`；装备/角色页用背包底板拼 10 槽，挂在 `K` 的页签里。
- 物品图标从 `sprite_item_stackable.NPK`/`sprite_item.NPK`/`sprite_item_common.NPK`
  的 28×28 帧人工挑；客户端没有 item ID → 帧号的名称表（`Script.pvf` 加密）。

## 五、聊天与存档

- **聊天框 = 真实消息流**：清房、领主出现、拾取、任务进度、获得经验/金币；
  不做玩家输入、不做多人、不做 NPC 对话以外的假聊天。
- **localStorage 跨局保留**：任务进度、背包、装备、金币、已解锁关卡。
- **重置只清任务/背包/金币/装备**；`records.js` 的通关记录与最佳时间**不清**。
- 存档要带版本号，能迁移；重置入口在仓库 NPC，二次确认。

## 实现记录（2026-10-24，第一遍：城镇场景）

- **原件**：`assets/import_dnf_town.py` 从 `sprite_map_grenselos.NPK` 烘了
  far/mid/grtile、6 种房屋、树/墙/桥/电线杆/沙袋/木箱/碎石；城门借
  `sprite_map.NPK` 的 `elvensgate` + `gatedoor`/`gatelight` 动画；NPC 从
  `sprite_map_npc.NPK` 烘了赛丽亚、敏泰、GSD、卡妮娜、布兰妮、辛达、
  守卫、守卫队长。输出 `assets/town.png` + `npc.png` 与两份 JSON。
- **场景**：标题按 Enter → 城镇；方向键走动、空格交互；30 身位宽、
  远景/中景/地面/物件四层；8 个 NPC 站在街上；走到城门按空格 → 地区地图。
  城镇没有战斗，底部沿用 HUD 条与红/蓝球。
- **验收入口**：`tests/browser/town-smoke.mjs` 证明「标题→城镇→8 NPC→与赛丽亚
  对话→城门→地区地图」，并截图 `tests/browser/artifacts/town.png`。
- **进度与任务第一遍**：`src/progress.js` 管 localStorage 里的金币、背包、
  10 个装备槽、三条任务与已通关关卡；`Core` 记 `stats.killsByType`，主线/猫妖/
  打碎三条任务分别接通关、击杀、破坏计数。赛丽亚/敏泰/GSD 在城镇接取与交付；
  主线奖励金币 + `starterBlade`，两条支线给金币 + 药水。`I` 背包、`L` 任务、
  `K` 装备三页，`1`/`2` 使用 HP/MP 药；`tests/progress.test.js` 覆盖存档、
  任务、装备与重置。
- **系统界面第一遍**：`assets/import_dnf_gui.py` 烘了商店、任务日志、背包、
  装备底板、NPC 对话窗、金币与物品图标到 `assets/gui.png`。I/L/K 三页与城镇的
  商店（卡妮娜：买 HP/MP 药、卖材料）、仓库（布兰妮：查看背包 + R 两次确认重置）、
  铁匠（辛达：分解第一件装备）都接上了；HUD 的 1–3 物品槽显示药/材料图标与数量。
- **回城**：通关/失败后按 `F4` 回城镇（`F3` 仍是地区地图）；任务、背包、金币保留。
- **装备与聊天**：精英/Boss 击杀按 1/3 概率掉 `锈蚀短剑`/`粗布上衣`/`铜戒指`
  （本片加成为 0）；`I` 背包里按 `E` 装备第一件，`K` 页看 10 个槽。
  城镇左侧画客户端旧式聊天窗，内容是真实事件流（最后 4 行）。
- **测试**：`town-smoke.mjs` 覆盖 8 NPC、接主线、三扇窗、重置确认、城门；
  `deep-smoke.mjs` 在通关后按 `F4` 验证回城。
- **还没接**：正式任务文本/商店排版（现在字压在客户端底图上）、
  深处的红蘑菇原件（客户端 set 02 里没有对应件；茅草屋已用
  `goblinkingdom/house.img` 补上，见 `ADR-0063`）、HUD 同机位逐屏校准。
  触屏代码已整段删除。

# 全场的步速照录像重标：他一秒走 2.05 个身位

**Status**: accepted（2026-10-14）。业主在 grill 上答 **「全部按照推荐」**
（Q6′ 选 c：**人与怪按同一比例压**）。

量自业主的整场录像 `dnf-dungeon-videos/00001-幽暗密林.mp4`（1920×1080、30fps、362.6 s，
游戏画面居中 1440×1080）。**265 视频像素 = 1 身位**。

## 这一片先纠正两个数

`docs/adr/0035` 那张表里有两行是**复核不出来**的，两个都在这条决定之前被重量推翻：

| | 0035 写的是 | 重量之后 |
| --- | --- | --- |
| 录像里他跑多快 | 330 视频px/s = **1.25 身位/s** | **520–555 视频px/s = 2.0–2.1 身位/秒** |
| 本作他跑多快 | 159 px/s = **1.89 身位/s** | **265 世界px/s = 3.155 身位/秒** |

- **录像那一个 330 是"房间宽 ÷ 他在房里待的时间"**（3013 px ÷ 9.1 s）—— 那个时间**含打架**，
  它不是跑速。重量用的方法是**分带互相关**测世界每秒滚多少像素（24 个 y 带结果完全一致，
  顺带证实中景/地面/前景是一整块 1:1 跟镜头滚），再用他脚下那个黄绿椭圆逐帧验证镜头 1:1 跟他。
  **单帧读会得到 330 或 870 这种假值**：逐帧位移是 −18/−29/−11 循环的，那是 30fps 采样拍到
  游戏帧相位的拍频，**要用 3 帧和（0.1 s）算**。
- **本作那一个 159 在代码里查无此物**：`PHYSICS.moveSpeed` 从第一个 commit 起就是 265，
  按住右键 0.5 秒走 132.5、1 秒走 265，匀速无加速段。（`159` 在 `core.js` 里只出现在一个
  不相干的地方：十字斩飞出去那一下的 `shot.speed`。）

**两个数都错，比值却撞对了**：0035 说 1.5 倍，真实的也是 **≈1.5 倍**。所以 0035 的方向没错，
错的是**目标值**。

## 决定

**一、全场的"位移速度"乘 0.65，落点是录像的 2.05 身位/秒。**

`PHYSICS.moveSpeed` 265 → **172**（2.05 × 84 = 172.2）。怪一起压：哥布林 95 → 62、
胆小的 118 → 77、牛头怪 68 → 44、投掷哥布林 76 → 49、冲锋兵 64 → 42、十夫长 72 → 47、
牛头巨兽 88 → 57。

**二、线画在"位移"与"出招"之间。**

压的是**一个身体或一块石头横穿场地有多快**：他的走、怪的走、怪扔出来的东西、Boss 的冲撞
（430 → 280）。**不压**的是起手、收招、冷却 —— 那些是本作自己的数，录像没量过，
而且它们量的是"他能有多久反应"，不是"场面滚多快"。

**三、为什么是"同一比例"，而不是各自取录像的绝对值。**

录像只量得出**两样**在走路的东西：他自己（2.05，三段独立样本）和哥布林（0.62–0.77，
两段样本、彼此差 24%）。**牛头巨兽、十夫长、投掷哥布林在录像里一次都没被量到**
（Boss 全程站在原地挥拳，没有横向走动的帧）。所以：

- **人的 172 是量的**，不是调的；
- **哥布林按下 ×0.65 是 0.74**，正好落进录像那段 0.62–0.77 里 —— 也就是说这一刀对哥布林
  **也是照录像**，不是折中；
- **其余每一样按同一比例走**，是因为录像答不上来，而同一比例是唯一能保住
  "原来那些怪之间的相对快慢"的压法。

## 顺带纠正一条记错的口径

`README.md` 的「下一步候选」里，把**哥布林的速度**记成了 118 —— 那是**胆小哥布林**的。
`grunt`（哥布林）是 **95**，也就是 1.13 身位/秒。所以「本作他 ÷ 怪 = 2.25、比录像的 2.9
拉不开距离」这个说法也是错的：真实的比值是 **2.79**，本来就贴着录像的 2.9。压完之后仍是 2.79。

## 代价与未决

- **哥布林那两个样本还是只有 2 段**（都在 (2,1) 那一间）；其余时间它们一直在出招或受击，
  找不到纯走路的窗口。要第三段得等到别的片子。
- **牛头巨兽的走速量不到**：它在 Boss 房全程原地出招，没有可用的横移帧。
- **深度轴（往屏幕里走）没动**：录像里斜着走时纵深被压到水平速度的 **0.56**，
  本作 `PHYSICS.depthSpeedRatio` 是 **0.75** —— 本作往屏幕里走得偏快。只有一只怪一段证据，
  置信度低，**没动**。
- **技能自己的位移一律不动**：十字斩那一步 0.54 身位、崩山击的跳、银光落刃的下砸，
  全是各自参考片里量出来的，和走速不是一回事。
- 过一间房从 **3.6 秒变 5.58 秒**（960 ÷ 172），录像最小那间 11.4 身位 ÷ 2.05 = **5.56 秒**。

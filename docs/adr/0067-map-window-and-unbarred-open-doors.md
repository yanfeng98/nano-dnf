# 默认方形地图，开门即撤掉门板

2026-10-29，业主对地图和清房不开门反馈选择「全部按推荐」，授权以下调整。

地图窗口默认方形整图，保留 Tab 切换圆形雷达。迷雾、玩家蓝柱、领主标记和清房后的相邻问号规则保持原定义。雷达只容纳约 2.5 格直径，开局的迷雾和裁切令路线难以辨识；方图能持续显示整关范围。此决定替代 ADR-0064 的默认开场雷达选择。

开着的门立即撤掉拦门板，保留客户端门拱和既有光效，不再等人物靠近才改变遮挡表现。渲染与 exitMode 使用同一状态。所有存活敌人与后续批次结束之后才清房，领主房沿用领主死亡结算。

沿用入口可回退的领域规则，并修复核心层提前拒绝通行的问题。未清房时要求主动走向入口外沿，以免出生、战斗靠近入口时误回上一间。普通清房门仍沿用原有门口范围。

实现和验证记录见 ../map-door-review.md；自动检查不代替业主实玩验收。

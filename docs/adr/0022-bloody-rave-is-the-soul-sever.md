# 「血气爆发」是这一招被叫错的名字，它就是嗜魂封魔斩

## Status

accepted（2026-10-04）。业主在看过两张逐帧对照图之后拍板：**「就是它，重做」**。

## 决定

`SKILLS.bloodyRave` 的中文名从「血气爆发」改成**「嗜魂封魔斩」**，并按训练房参考片
`assets/dnf_src/bilibili/skill-clips/09_嗜魂封魔斩.mp4` 把它从 0.5 秒的小上挑波**重做成它本来的样子**
——一条约 4.9 秒、可松手截断的吸附引导（那一条单独写在 `0023`）。

**id 保持 `bloodyRave` 不动。** `BloodyRave` 正是客户端自己给这一招起的名字（`dnf_effect_picks.md`
第 66–87 行把客户端自带的预览片定为英文名的权威来源），错的是中文名，不是 id。

## 取证

**两张片子逐段对得上——不是"像"，是同一套动画：**

| 客户端自带预览片 `Swordman-BloodyRave.avi`（173 帧） | 训练房 `09_嗜魂封魔斩.mp4`（176 帧） |
|---|---|
| `#1–#14` 待机 | `#1–#32` 待机 |
| `#15–#29` 掌心凝出一颗红球、长大成盘 | `#42–#52` 同一件事 |
| `#30–#130` 一大团漩涡持续翻搅 | `#59–#152` 同一件事 |
| `#131–#139` 收 | `#153–#156` |
| `#140–#150` 金色爆发 | `#162–#170` 金色巨叉 |
| `#151–#172` 跪下 + 地面一片红晕 | `#171–#176`，而**收招（蹲着站起来）落在下一条片子 `10_崩山裂地斩.mp4` 的 `#1–#3`** |

另外两条账对不上：

- **素材账**：`assets/import_dnf_effects.py:67` 从这个包里只取了 **1 个条目**（`lslash-normal.img`，
  234×224、均色 `(174,15,0)`），而包里另外 26 个条目里躺着 `wind_charge` / `loop-normal` / `loop-dodge`
  / `line-normal` / `line-dodge` / `finish_normal` / `finish_dodge` / `start-normal`——**正是参考片里
  那颗血球与那团漩涡**。一条 0.5 秒的招式不会把一个漩涡专用的包装到自己名下。
- **两份台账是错的**：`assets/dnf_src/skill-body-match/INDEX.txt:8` 与 `assets/dnf_effect_picks.md:83`/`:212`
  都写着「血气爆发 ← BloodyRave」。那是当年**归错了主人**，形状和 `0003`（红归架势）、
  `0016`（暴走不是血之狂暴）一样：**量对了，主人安错了。**

## Considered Options

> **保留「血气爆发」、另开一条新技能。** 否。两条技能会共用同一个包里的相邻条目——`lslash-normal`
> 在这个包里本来就是这一招的一部分——将来没人讲得清"这一笔是谁的"。而且那要给技能栏加第 13 格，
> 而这一招本来就有自己的格子（H）。
>
> **只改中文名，机制不动。** 否。0.5 秒和参考的 4.9 秒差着一个数量级；名字改对而招式还是那一记
> 小上挑波，只会让下一个人以为"参考没吃透"。

## Consequences

- **面板上的「血气爆发」这个名字消失**，H 键那一格从 0.5 秒的小上挑波变成约 4.9 秒的引导大招。
  `SKILL_ORDER` 长度不变（仍然 12），所以 `effects.png` 那 7 行附加行**不用挪位**——
  这一片原本按"新增第 13 个技能"估的工作量因此作废（grill 的 Q7）。
- **`assets/dnf_effect_picks.md` 的第 83 / 212 行要改**：`BloodyRave` 的主人从「血气爆发」改成「嗜魂封魔斩」。
- **颜色上有一处两源冲突**：客户端预览片里那团漩涡是**白金**的，训练房参考片里是**血红**的。
  按 `0006`（色板由片子定）走**红**。那个包带 `(18)` / `(tn)` 两套色板，实现时两套都量一遍再定，
  量出来的数写进台账。
- **旧技能的数全部作废**：0.5 秒 / `mp 16` / `cooldown 4.5` / 那记上挑波与 `juggle`，重做后一个不留；
  新的数连同量法一起写在 `SKILLS.bloodyRave` 的注释里（照 `mountainRift` 那条的写法）。

## 验证

除了单元测试，还有一条**浏览器级可玩性证明**（`npm run test:browser`）：起本地静态服务，用无头 Chromium
打开真实页面，用和单元测试同一套策略驱动机器人通关整座地牢，跑**两条通路**——键盘（真实按键事件）与
触屏（真实 DOM 指针事件，`hasTouch` 上下文 + `?touch=1`），并校验控制台无报错、页面无异常、资源全部
200、WebAudio 已初始化。最近一次结果：

```
keyboard victory=true kills=35 damageTaken=162 seconds=101.5 level=5  audio=created/running sfx=68/68 rain=true forest=true  drag=月光斩→槽A persisted=true
touch    victory=true kills=35 damageTaken=168 seconds=88.6 level=5  audio=created/running sfx=68/68 rain=true forest=true  touchMode=true muteToggle=ok
consoleErrors=[] pageErrors=[] failedRequests=[]
assets: index.html / loadout.js / main.js / render.js / core.js / slayer.png / skills.png / effects.png / rift.png / weather.png / favicon.png 全部 200
```

第九十二切片起，`kills` 从 14 涨到 **35**（两批怪），机器人也走得更久（101.5 / 88.6 秒）；
两条通路仍然通关，但都是残血（162/168 对 176）—— 这是**业主加怪之后的难度**，不是测试红了；
他人肉玩时会不会觉得太硬，要等他实玩说。

键盘那条通路还会顺便验证编成：按 `B` 打开面板 → 用指针事件把「月光斩」拖到槽 A → 读回
`getLoadout()` 与 `localStorage` 确认已生效 → `resetLoadout()` 复位。截图见
`tests/browser/artifacts/loadout-panel.png` 与 `loadout-applied.png`；本切片新增的「断桥」混合房与
Boss 狂暴第二阶段、精英剑卫的旋风分别见 `room-mix.png`、`boss-phase2.png` 与 `elite-spin.png`，
通关翻牌的四张牌与领奖详情见 `reward-cards-*.png`、`reward-reveal-*.png`（都由同一次浏览器跑动产出）。
每次跑动的日志还会按房间记录承伤来源，并校验「四张牌、面朝上、倒计时自动选最左、物品来自青色名池」
「通关成绩确实写进了 localStorage」，以及「标题界面停留 3 秒期间 `state.time` 仍为 0、未掉血」，
方便判断新机制是否真的生效、老缺陷是否真的修好。带记录标题界面见 `title-record.png`。

两条通路各自使用独立的浏览器实例（否则两条 rAF 循环会互相抢 CPU，输入时序被拖慢）；
只跑其中一条可以设 `PASSES=touch npm run test:browser` 或 `PASSES=keyboard`。

**截图证据**：`tests/browser/artifacts/` 下只有**能证明改动的那几张**会被提交——常见的是
`playability-title.png`、`playability-keyboard-fight.png`、`playability-keyboard-clear.png`、
`playability-touch-start.png`、`playability-touch-fight.png`、`playability-touch-clear.png` 这六张
（标题、键盘打一场、键盘通关、触屏界面、触屏打一场、触屏通关），再按当片需要补一张它自己特有的
（第五十五切片的地板见 `chapel-hazard.png`，第五十六切片的新四向键见 `playability-touch-start.png`）。

目录里其余三十多张**每次跑动都会重新生成**，而且常常只是因为 HUD 里那行计时文字变了就变
（`用时 1:05.1 → 1:13.7` 这种）——全提交等于每片往 `.git` 里塞十几兆噪声（历史上一度累计到 468MB）。
所以那些图的字节**就停在它上一次被提交的样子**，跑完 `npm run test:browser` 之后会显示为「已修改」：
**丢掉，不要提交**。`git checkout -- tests/browser/artifacts` 一把还原，然后只 `git add` 上面那几张。

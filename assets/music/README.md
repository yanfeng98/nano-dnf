# assets/music —— 这一关的两首曲子

**这里要放两个文件**，文件名是写死的（`src/music.js` 的 `TRACKS`）：

    assets/music/mirkwood.ogg         关卡（幽暗密林）
    assets/music/mirkwood_boss.ogg    Boss 房

## 它们从哪儿来

**客户端的 `Music\` 目录**（`C:\dnf\地下城与勇士\Music\`）。DNF 的音乐不是藏在加密包里
的，就是那个目录下的明文 `.ogg`。业主 2026-10-12 在 grill 上定的口径：**要原曲，不要合成器**
（Q6 选 b），而且**先去客户端拿**、拿不到才回落到从录像里抠（Q7 选 c）。

**为什么非要客户端那一份**：从录像里抠拿到的是 bilibili 转码过、**已经削顶**的有损音频，
而且**六分钟里没有一次循环**（量过：只有 8.5–9 秒的乐句周期），循环点得手工硬接；
客户端那边是**无缝循环的源文件**，而且**关卡与 Boss 房是两首**（量出来录像里 Boss 房
也在换），抠录像只能得到一首。

## 在它们到位之前

`src/main.js` 里那一层会**回落到合成器**（`src/music.js` 的 `pumpMusic` 那套，
96 BPM、Am–F–C–G、10 秒循环）—— 所以这个目录是空的时候游戏照样有音乐。

**文件一放进来，合成器那条路就永远走不到了。** 那时按 `docs/adr/0038` 把它整条删掉
（连同 `tests/music.test.js` 里守着它的那几条），别留着两套音乐。

## 出处

这两个文件是**客户端自带的原曲**，不是本仓库的作品。它们进版本库是业主 2026-10-12
在 grill 上定的（Q9 选 c：进 git，并在 README 与 ADR 里记明出处）。本仓库早就在提交
从同一个客户端烘出来的美术（`slayer.png` / `monsters.png` / `forest.png` / `effects.png`），
音乐与那批图是同一个来路。
